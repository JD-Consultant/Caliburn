# JD 著作

JD 著作 context 負責從員工工作材料形成可確認的職務模型，並將已確認內容整理為職務說明書。AI 提供分析與候選，
員工保有文件決策權。

## Language

### 工作結構

**主要職責（Duty）**：
由共享主要目的的一組工作任務歸納而成的角色責任範圍。
_Avoid_：把主要職責當成尚未訪談即可確定的分類盒、以 `T1` 代替領域名稱

**工作任務（Task）**：
角色目前承擔、具有明確工作結果、能作為一項責任被指派與檢核，並屬穩定例行或正式低頻責任的工作單位。
_Avoid_：操作步驟、工具名稱、單次故事、動作清單

**工作產出（Output）**：
工作任務形成的關鍵過程或最終成果；可以是文件、服務、狀態改變或判斷結果，不強迫每項任務都有實體成品。
_Avoid_：把所有活動本身當成產出

**行為指標（Indicator）**：
用來判斷工作任務是否成功完成的可觀察行為、產出或品質條件。
_Avoid_：KPI、操作步驟、只憑工作產出自動推導的正式答案

**知識、技能與態度（KSA）**：
完成特定工作任務與行為指標所需的工作者能力內涵；描述職務要求，不代表目前員工已具備。
_Avoid_：脫離工作任務的形容詞清單、把員工接受候選當成能力證據

**員工確認 JD 草稿（Employee-confirmed JD Draft）**：
由員工直接編輯或確認 AI 提案後形成的目前職務說明書；可供後續審閱，但不代表企業正式核准或 SME 共識。
_Avoid_：正式核准 JD、企業政策、把 current draft truth 稱為 organizational authority

### 發現與確認

**工作故事（Work Story）**：
員工對具體工作情境、行動與結果的敘述，是發現與佐證工作內容的材料，不是工作任務本身。
_Avoid_：Task、完整職務清單

**暫定職務框架（Provisional Role Frame）**：
由職位範圍、既有文件與參考基準形成、仍可新增、修正或否定的工作假說。
_Avoid_：正式 JD、封閉職責清單

**混合式職務發現（Hybrid Job Discovery）**：
以暫定職務框架引導覆蓋、以具體工作敘事提供證據，再經跨敘事整併、結構化檢查與人員確認形成職務模型的方法。
_Avoid_：純上而下填表、純故事自動生成
