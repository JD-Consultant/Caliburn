# 完成度反方檢查

## 適用時機

- 某一訪談焦點準備暫時收束、切換，或整份內容看似接近足夠。
- 員工詢問目前進度、還缺什麼、是否可匯出。
- 新更正可能讓先前的充分性判斷失效。

本方法只給 advisory sufficiency 與具體 gap；不建立暫停、結束本輪或完成訪談狀態。員工可停止傳訊息、關閉頁面或自然繼續。

## 所需證據

- 已保存的員工來源、更正 lineage、可修訂理解、訪談工作、待處理 gap。
- 核准文件與待員工審核／拒絕／延後的變更。
- Task／Duty／O／P／K／S linkage 與來源覆蓋。

## 產出

- 目前為何足夠或不足的白話說明。
- 最重要且具體的 remaining gaps 與繼續訪談的可能收益。
- 若還要問員工，整輪只保留**一個主要問題**；其餘變成可見待處理項。
- 不使用假精確百分比，也不把欄位數量等同專業完整性。

## 缺口

逐項反方檢查：

- **例行工作遺漏**與 routine omission。
- **精彩事件偏誤**，異常案例遮蔽日常責任。
- **他人工作**、**過去工作**、**一次性工作**被誤收為目前本人責任。
- **過度合併**、**過度拆分**、**重複 Task**。
- **無來源 O／P／K／S**，或模型推論冒充員工證據。
- 未解的**高影響矛盾**、本人／他人責任、Task 邊界或結構前提。
- Duty 分組尚不合理、Task 未分組、待審變更未決或員工保留 unknown。

## 防止臆測

- 不為了宣稱完整而補造缺失內容。
- 不把員工按接受視為內容必然正確；仍檢查內部一致性與來源。
- 不把匯出視為接受待審變更，也不因強制匯出隱藏 gap。
- 不把模型信心、工具呼叫數或對話長度換算成進度百分比。

## 重新開啟

任何新來源、更正、直接編輯、審核決定、Task／Duty 結構變動或 OPKS linkage 改變後，受影響範圍的充分性都要重新計算。
