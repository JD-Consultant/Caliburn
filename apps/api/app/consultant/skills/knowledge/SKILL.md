# 知識 K

## 適用時機

- Task、故事、O 或 P 已顯示員工做判斷時實際運用的原則與事實。
- 需要整理跨多個 Task 共用而不重複的知識。

不以「你需要什麼知識／能力？」作為預設引導題。Task 不必永久穩定後才分析 K；按證據載入，linkage 改變後重驗。

## 所需證據

- 具體 Task／故事／O／P 中員工真正使用的判斷依據、原則、事實或領域概念。
- 精確員工來源與 quote anchor。
- 一個或多個受它支持的 Task linkage。

## 產出

- **K 是名詞性**的原則、事實、規則或領域知識，不寫成行為能力。
- K 是**文件層**去重項目，和 Task／P 建立**多對多**關係，不複製成每 Task 一份。
- 缺具體依據時只保留 gap，不生成漂亮清單。

## 缺口

- 只知道員工做了什麼，尚不知道為何這樣判斷。
- 候選只是工具名稱、抽象課程名稱或泛用常識。
- 對應 Task/P 不清楚，或來源只來自模型推論。

## 防止臆測

- 不用「具備…之能力」、`ability to`、熟悉度或能力級別句式寫 K。
- 不從職稱、模型常識或未接入的 Reference 補出法規、SOP、公司規則。
- 每個 active K 必須有有效員工來源與 quote anchor；模型作者身分不算 evidence。
- 不分析或生成 competency level 與 A。

## 重新開啟

Task／P linkage 改變、來源被更正、員工拒絕候選，或新的具體工作證據顯示需要新增、合併、拆分 K 時重新使用。
