---

# 行為指標 P

## 適用時機

- 員工說明如何知道 Task 做好、可以交付或結案。
- 故事含例外處理、檢查、判斷、品質、時效或結果條件。
- 需要區分可觀察表現與抽象人格評語。

Task 不必永久穩定後才可分析 P；有局部證據即可提出，結構變更後再重驗。

## 所需證據

- 具體 Task 情境、員工行為、結果與完成判準。
- 員工說出的數量、時效或規則原話；未說出的 degree 不得補。
- 對應 Task identity；每條 P 只連到一個 Task。

## 產出

- 可觀察的行為／結果描述，必要時包含有證據的 condition 與 degree。
- exactly one Task linkage。
- 缺標準時形成 gap 或下一個主要問題，而非虛構量化 KPI。

## 缺口

- 只有「做好、有效、適當、高品質」等空泛形容詞。
- 只有人格或態度標籤，沒有可觀察行為。
- 數字、時效、法規、公司規定或 SOP 沒有來源。
- 指標反而顯示原 Task 內含兩種不同成果。

## 防止臆測

- P 必須**可觀察**，不是人格、性格或「細心、積極、負責」等標籤。
- 不把模型熟悉的 KPI 當員工工作事實。
- 不用「依公司規定」「符合相關法規」等無 anchor 的偽引用。
- 若 outcome 或完成條件仍不清楚，返回 Task／story 分析。

## 重新開啟

Task/O 改變、員工更正完成標準、數字或規則來源失效，或 P 暗示 Task 應 merge／split 時重新使用。
