# 一句話判準
態度=「內在動機及行為傾向」,從官方 A01–A14 目錄挑 2–4 條,放**文件層**
(不逐任務),且**從他講過的故事聽出來再提議**,他點頭才算。

# 官方目錄 A01–A14(iCAP 指引 p76;提案只從此池選,可增列須明說是自訂)
A01 主動積極 · A02 正直誠實 · A03 親和力 · A04 持續學習 · A05 自我管理 ·
A06 自信心 · A07 追求卓越 · A08 團隊意識 · A09 彈性 · A10 壓力容忍 ·
A11 應對不確定性 · A12 好奇開放 · A13 冒險挑戰 · A14 謹慎細心

# 判別規則
- 官方定義:「個人對某一事物的看法和因此所採取的行動,包含:**內在動機及行為傾向**」
  (iCAP p37)。
- 位置規則(iCAP p37/p76 逐字):「合併呈現於職能基準下方欄位」——**文件層一次呈現,
  絕不掛在單一任務下**。
- 問法:**絕不直接問**「你的工作態度是?」「你細心嗎?」;從故事編碼(BEI 通則):
  他描述的實際行為對上目錄某條,才提議「聽起來你很謹慎細心?」。
- 與 K/S 界線:可由訓練發展的能力=S;較穩定的行為傾向=A。
  「其他特質」(不易由教育訓練改變者)官方明訂**不納入基準**(iCAP p37 註)。
- 描述語言可借 O*NET Work Styles 16 項(每項一句可觀察定義,如 Dependability=
  「可靠、負責、履行義務」)讓提議更具體。

# 好壞例(成對)
- 壞:直接問「你細心嗎?」——引導式問句,誰都答是,無證據力。
- 好:他說「每批我一定重秤一次才放行,慢也認了」→ 提議 A14 謹慎細心(附這句當佐證)。
- 壞:一口氣選 8 條——全選=沒選;挑最有故事佐證的 2–4 條。

# 邊界案例
- 2–4 條為宜(本 repo 校準值;官方只規定「挑選、可增列」未定條數)。
- 他自述的態度沒有故事佐證 → 先追一個實例再決定收不收。
