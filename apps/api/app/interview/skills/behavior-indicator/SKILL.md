# 一句話判準
行為指標=在什麼情境下做出什麼**可觀察**行為或產出、到什麼標準——
第三者看了就能判定有沒有達成。

# 判別規則
- 官方定義:「用以評估是否成功完成工作任務之標準。需具體描述**在何種任務情境下,
  有哪些應有的行為或產出**」(iCAP 指引 p37)。
- 官方指定句式:STAR(情境/任務/行動/結果)或 ABCD(對象/行為/條件/程度)(iCAP p48)。
- 能力程度應可對應該任務之職能級別(iCAP 審核指標 3.4.3)——寫 4 級任務的指標,
  措辭就要有「獨立、規劃設計」的高度,不能寫成照表操課。
- 動詞必須可觀察(Bloom 修訂版 19 認知歷程動詞):辨識、回憶、詮釋、舉例、分類、
  摘要、推論、比較、解釋、執行、實作、辨別、組織、歸因、檢核、評論、產生、規劃、製作。

# 禁用動詞(Krathwohl 2002/Airasian:不可觀察或含混,觀察者無法判定達成)
了解、知道、熟悉、認識、掌握、意識到、體會、重視;
「說明、列出、展示」慎用——偏評量情境用語,寫進指標常變成背誦題。

# 好壞例(成對)
- 壞:「了解檢驗流程」——不可觀察,從記憶到創造都能自稱「了解」。
- 好:「依進料檢驗規範執行抽樣檢驗,並於當日完成允收判定與紀錄」
  ——情境(進料)+行為(執行、判定)+標準(當日、有紀錄)。
- 壞:「具備良好溝通」——形容詞;好:「向產線說明檢驗異常原因並確認對方複誦要點」。

# 邊界案例
- 操作型任務沒有工作產出時,成果寫進指標(對應 output-writing 的合法 n/a 規則)。
- 指標寫「行為」不猜「內心」:寫可外部觀察的動作,別假設內在歷程(Bloom push-down
  principle:看似高難度的任務,執行者可能在低層次操作)。
