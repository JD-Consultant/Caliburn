# 一句話判準
K=執行任務所需了解的「**原則與事實**」,寫成名詞化概念;
S=可幫助任務進行的「**操作/認知/社交能力**」,寫成動作短語。

# 判別規則
- K 官方定義:「執行某項任務所需瞭解可應用於該領域的**原則與事實**」(iCAP 指引 p37)。
- S 官方定義:認知或技術操作層面能力(hard skills)+社交、溝通、自我管理等
  (soft skills)(iCAP p37/p74)。
- 句式(ESCO 官方慣例):knowledge **不用動詞、不加「知道/知識」**——
  寫「發酵製程」,不寫「知道發酵製程」;skill 用動作短語——「操作 CNC 車床」。
- 操作型基準的 S 以**實際操作性技能敘述**為主,如「CNC 車床操作」(iCAP p74)。
- K/S 都須**對應行為指標**,禁孤兒、禁重複(iCAP p49)。
- 軟技能參考指引附件之共通軟技能清單(可增列);**S/K 碼是每份基準各自編號,
  沒有全域固定目錄**——提案一律以系統注入的官方池為準,絕不憑記憶背碼。

# 快篩問句
- 問 K:「做這步之前,要先**知道**什麼?」→ 答案名詞化(原理、規範、參數)。
- 問 S:「實際上怎麼**操作**?哪一步最見功力?」→ 答案動作化(操作、判讀、協調)。

# 好壞例(成對)
- 壞 K:「會操作 SPC 軟體」——這是 S。好 K:「統計製程管制(SPC)原理」。
- 壞 S:「品質知識」——這是 K。好 S:「量測儀器校驗操作」。
- 同一段話常拆一 K 一 S:「要懂鍍膜參數(K:鍍膜製程參數),還要會調機(S:鍍膜
  設備參數調校)」。

# 邊界案例
- 分不清時用 ESCO 對照:「原則與事實的體系」=K;「應用知識與 know-how 完成任務、
  解決問題的能力」=S。
- 較穩定的行為傾向(細心、主動)不是 S,是態度 A(見 attitude-writing)。
