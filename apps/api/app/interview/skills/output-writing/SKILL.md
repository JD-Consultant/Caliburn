# 一句話判準
工作產出=可交付、可查核的**有形標的名詞句**(書、文件、圖表、資料),不是動作。

# 判別規則
- 官方定義:「執行某任務最主要的關鍵工作產出,**包含過程及最終**的關鍵產出項目」
  (iCAP 指引 p37)——過程產出也算,不只最終成品。
- 官方句式要求:「儘量以書、文件、圖表等**有形交付標的**為主」(iCAP p37 逐字)。
- **合法 n/a 規則**(iCAP p37 逐字):「若該項任務僅有行動或操作性質之工作成果,
  則不必列出工作產出,建議將相關成果列於行為指標之描述中」——操作型任務
  **可以沒有 O,不硬湊**;把成果寫進該任務的行為指標。
- 國際對照:O*NET/NOS 皆無獨立產出欄——產出內含於任務句的「to+可查核結果」;
  由此反推判準:產出必須是**名詞化物件(Things/Data)**,不是活動本身。

# 訪談問法
「這件事做完,會留下什麼東西?」(文件?紀錄?系統裡的一筆資料?)
「別人怎麼知道你做完了?」——答案若是「一份 X」就是產出;若只是「做完了」則走 n/a。

# 好壞例(成對)
- 好:「進料檢驗報告」「首件檢查紀錄表」——名詞、有形、可查核。
- 壞:「完成檢驗」——動作,不是交付物 → 改為檢驗留下的紀錄,或併入行為指標。
- 壞:「品質很好」——形容詞,無法查核。

# 邊界案例
- 一條任務可有多個關鍵產出,並列即可。
- 口頭回報、現場操作類任務 → 走合法 n/a,成果併入行為指標,別發明「口頭報告」湊數。
