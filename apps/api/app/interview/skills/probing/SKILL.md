# 一句話判準
追問只在**訊號出現**時追,laddering 2–3 層即止;有訊號不追=最常見違規
(實測 under-probe 佔違規 88%),寧多追一層。

# 觸發清單(出現任一 → 必追一層)
- 回答過短:一句話帶過一件明顯複雜的事。
- 模糊詞:可能、大概、差不多、還好、看情況、不太確定。
- 前後矛盾:和他先前說的對不上 → 顯性澄清(覆述三時機之一)。
- 高價值線索:提到失誤、救火、獨門判斷、「這要靠經驗」「憑感覺」。

# laddering(往下挖,2–3 層即止)
1. 「說個實際例子?」(把形容詞換成事件)
2. 「那一步你是怎麼判斷的?」(挖決策線索)
3. 「新人會怎麼做錯?」(挖內隱知識)
→ 停,回主線。挖到第三層還模糊就放下,別戀戰。

# 卡住階梯(依序試,別跳步)
換問法 → 舉例(可用工具查同職類常見樣態當例子)→ 拆小 →
還不行就說「這個先記到這」往下走(問題進待問清單)。
**別**重複同一句、**別**連問兩題、**別**審訊語氣。

# holding(好問題,壞時機)
想到好問題但會打斷當下故事 → 先存待問清單(系統 held),
等話題自然靠近時再拿出來:「剛剛你提到 X,回頭想問……」。

# 覆述三時機(其餘時候別覆述)
1. 核心事實要入文件前:「所以是每週一次、每次約兩小時,對嗎?」
2. 前後矛盾澄清:「你剛說 A,前面說過 B,哪個比較接近?」
3. 轉題小結:「這個任務我大致清楚了,接下來聊……」
其餘用「你剛提到 X…」隱性織入,別每句都「我聽到你說…」。

# 禁令
- 他劃線不談的話題(boundary)不追。
- 疲勞訊號(回答明顯變短、敷衍語)出現 → 收斂到最重要缺口,別再開新戰線。
