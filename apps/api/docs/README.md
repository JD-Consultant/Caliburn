本目錄提供正式 App 後端的閱讀入口；模組責任、契約與接線以現行程式及下列文件為準。

- 安裝、執行與已知限制：[後端 README](../README.md)。
- 模組、契約、保存與執行設計：[實作文件入口](../../../docs/implementation/README.md)。
- 後續任務及驗收狀態：[架構與現行責任](../../../docs/architecture/README.md)、計畫入口；原重建計畫已結案，供追溯施工與驗證。
- 正式產品權責依 [正式產品與選型](../../../docs/architecture/design-decisions.md)，公版工具的可選接線依 [公版明示接線](../../../docs/architecture/rag-pipeline.md)；[現行產品架構](../../../docs/architecture/README.md)是舊產品沿革。

此處不複製第二套設計文件。舊 API 的退役脈絡見 [RAG 服務邊界](../../../docs/architecture/rag-pipeline.md)及歷史入口；本頁原文可從 `def9c248:apps/api/docs/README.md` 讀回。
