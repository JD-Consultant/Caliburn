# ADR0082：顧問以 JD 工作計畫延續長任務

- 日期：2026-10-07
- 狀態：**Accepted（2026-10-08）；使用者確認分工後授權實作與測試，品質效果另行驗證**
- 議題：INTPLAN 後續
- 部分取代：[ADR0081](0081-consultant-interview-focus-and-unresolved-plan.md)決定 1 的「只記重要未知、已解移除、大綱完全留在 Memory」；其餘工具、保存、原能力、採用及效果驗證責任保持。
- 詳細設計：[INTPLAN §10–11](../specs/2026-10-06-consultant-interview-planning-and-focus-design.md#10-jd-工作計畫內容與用法)
- 施工準備：[變更計畫](../plans/2026-10-07-jd-work-plan-alignment.md)；效果驗證：[新比較協議](../experiments/product-validation/jd-work-plan-comparison-2026-10-07/protocol.md)

元件名稱、責任及關係沿[架構文件 §2.1](../architecture/system-boundaries.md#21-長任務的元件分工)；Changes 為變更檢視，既有程式命名保持。採用範圍為 Plan 的內容用途、指引與文案；工程完成與真模型品質由施工及比較證據分別判定。

## 脈絡

原筆記已能保存、局部編輯及在換窗後提供精確文字，但八案比較仍有重要漏項、未有效返回及未知語意變形，尚未證明穩定提升 JD 品質。使用者進一步要求：Agent 要自主規劃整個長訪談，追蹤尚未深入及尚未完成的分析／成品工作，而不只保存未知。

OpenAI 的計畫／ExecPlans、Anthropic 的長任務 harness、ReCAP 與 Plan-and-Act 都包含目標、工作安排及進度的某種外化；格式、保留完成資訊及是否另呼叫 planner 並無統一答案。機制與原始來源見[研究 §20](../research/work-analysis/2026-10-06-long-interview-planning-and-focus-research.md#20-2026-10-07-memory-與-plan實際公開設計比較)。本提案選擇沿用本案已有資料權責及同一 A，效果須另驗，不把公開案例當本產品品質保證。

## 決定

1. Memory 保存目前工作理解、範圍、依據與不確定性；Plan 安排目前焦點、主要方向的處理位置及剩餘訪談／分析／JD 編修與核對；JD 為實際交付成果。Plan 可帶必要短脈絡，不作 JD 事實引用或第二份 Memory。
2. 沿一份短 Markdown，以「目前焦點／工作方向」作閱讀慣例。有需要才展開文字子項，不新增任務 ID、固定狀態、百分比或任務表。主要方向可短留有範圍的進度；完成微步驟移除，未知命題及重要未完工作不得因精簡而變義。
3. 同一 A 先取得輪廓、選焦點；新輪對照全文，有實質變動才局部 patch；離開焦點時保住剩餘並回看整體，交付前依指南核對實際 JD。保留必要再訪條件及受訪者停止意願，不增加固定重規劃呼叫或答覆後自主背景 Turn。
4. 沿現有 read／edit wire、V4A、候選保存、原操作／request 恢復、合法跨輪採用與精確壓後投影。對外文案改為「工作計畫」，UI 仍呈現同份唯讀正文；不因更名遷移資料或改寫舊保存請求。
5. Plan 與 Diff 是 Agent 的獨立元件。A 可使用既有差異、目前稿與依據，判斷剩餘工作是否改變；本提案不修改 Diff 的提示、比較或恢復契約，也不以新增 Diff 能力作為 Plan 的前提。Plan 的 V4A patch 是局部修改方式，與提供變更資訊的 Diff 元件分開。
6. 以共同指引、相同既有 Diff 能力及一致披露條件的新配對，比較有無 Plan 支援對正式 JD 的影響。工程保存通過、工具成功、Plan 文字漂亮或自行標完均不代替成品品質；原八案只作歷史依據。

## 替代方案與後果

- **維持未知清單：** 改動最少，但未輪到的已知未入稿工作無法留在清單，換題後需從其他資料重建。
- **只留剩餘工作：** 正文較短，但方向消失時難分辨已處理與未探索。選定短大綱作候選，並以局部完成被誤當全案完成的反例防止過度概括。
- **完整自足計畫或獨立 planner：** 可承擔更多執行脈絡，但增加與既有 Memory／JD 的重複或模型呼叫、恢復及費用責任；目前沒有必要性證據。

本決定主要改變 Plan 的模型指引、工具說明及文案。Changes 沿其獨立責任文件；資料表、候選採用、B1／B2、JD 來源與產品控制沿原責任。新風險是進度過時、正文膨脹、完成錯覺以及 Agent 仍不回看；因此保留真實成品與過程反例的有限比較。

本決定不宣稱比較已完成或品質達標，不授提交、merge、push、發布或資料處置。索引標示與 ADR0081 的 successor 關係，ADR0081 原文保持不變；後續若變更本決定，另循 successor 流程。
