# Architecture Decision Records (ADR)

每份 ADR 記錄**一個**重大決策的脈絡、決定、與後果(取捨)。格式採輕量 Nygard 式。
ADR 是「為什麼」層;搭配 `../specs/`(細節設計)與 `../runbook.md`(怎麼操作)。

> 規則:ADR 一旦 Accepted 就**不改內容**;要翻案就新開一份 ADR 標 `Supersedes`/`Superseded by`。
