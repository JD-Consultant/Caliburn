# ADR 0027 — 訪談引擎 v2:顧問 agent + 書記 + 確定性覆蓋帳本(四組件)

- **狀態**:Accepted(2026-07-08)。
- **研究依據**:[`../specs/2026-07-06-consultant-not-formfiller-redesign-research.md`](../specs/2026-07-06-consultant-not-formfiller-redesign-research.md)
  (八輪:§1 診斷、§7–8 架構收斂、§9 核准 UX、§10 三角度驗證、§11 放行標準他山之石、
  §12 實作對權威、§13 反向最終檢驗、§14 帳本門檻 v1)。
- **關聯**:互動模式=ADR 0020;無狀態回合=ADR 0023(留用);select_schema=ADR 0024(留用);
  共編權限=ADR 0025(**本 ADR 修正其第 1 點**);模型 role=ADR 0026(沿用擴充)。

## 脈絡

真人試訪(2026-07-06)判定 v1 引擎=「填表格機器人」:逐欄位問、單任務鎖、不查資料、
不引出 OPKS、員工卡住不幫——與北極星(取代職務說明書顧問)差距是**架構性**的,不是
prompt 可修。八輪研究(BEI/職能方法論、AI 訪談平台 2024–26、大廠 agent 指南 2025–26、
AI 訪談員論文、iCAP/O*NET/IfATE 官方標準、OWASP、反向對差)收斂出本設計;
反面教材:無狀態機的 LLM 自判進度系統,88% 追問違規(arXiv 2410.01824)。

## 決定

### 四組件(2 LLM + 1 確定性程式 + 1 backstop LLM)

1. **顧問 agent**(對話唯一主導;強模型):單線程、手刻工具迴圈(上限 N 次/回合),
   **READ 工具**查職能基準(搜職類/列任務/查職能/白話反查=KnowledgePort);**無寫入權**
   ——回覆零格式負擔,才能共情、舉例、追問(BEI 式:先聽故事)。
2. **書記**(獨立抽取 pass;便宜模型):讀逐字稿增量,產 guarded writes 交**既有 executor**;
   **兩通道**:對上官方 → strict enum 池選(零幻覺=宣稱官方必真官方);對不上 → 自訂
   (自由名+逐字 quote 溯源+人審)。**跨任務歸位**(items:match;丟棄 focus 單鎖)。
3. **確定性覆蓋帳本**(純程式,非 LLM):per-interview 槽位狀態表 + 三純函式
   (`next_gap`/`is_stalled`/`can_finish`);**完成閘門**擋早收、**飽和偵測**(連續 2 次
   追問無新槽 → 標記、換題)防死鎖;深問分層 core/淺掃由「比重×頻率」建議(人可改)。
4. **backstop 複查**(收尾;便宜模型):只答兩題(漏記?出處成立?),**只提案**給
   建議層,不直寫。

### 門檻 v1(§14,黃金範本校準)

任務必問頻率+比重(**全文件比重加總=100%** 為確定性檢查);core=12 槽全套、淺掃=4 槽;
O ≥1 有形產出(操作型可合法 n/a,iCAP 規則);每職責 P ≥1 條「指標+目標值」;
K、S 各 ≥2 且掛任務(禁孤兒);**A=文件層一次,2–4 項自 A01–A14 官方池+每項一句訪談印證**;
收尾=員工快速再確認(iCAP 驗證步單人版)。門檻為假設,由 interview_sim + 黃金範本校準。

### 互動與核准(修正 ADR 0025 第 1 點)

- onboarding 併入對話(空白文件可起跑;手動 picker 平行保留);選擇用清單(AI 預勾)、
  敘述用對話。
- **風險分層**:高風險/影響結構(選職類、任務清單、加自訂項、模糊歸類)→ 選單阻斷確認;
  低風險 → 自動落地+「待確認」標記+自然節點批次審+undo。**不再有「人沒碰過就直改不標記」
  ——AI 寫入一律進可審層**(0025 其餘各點不變)。

### 實作形(§12/§13)

手刻工具迴圈藏 `LlmPort` 後(12-Factor Agents;Pydantic AI=唯一升級門);書記序列先行
(並行=未來縫);開場 AI 揭露+時長+資料用途(NN/g);員工輸入=**資料非指令**(OWASP
LLM01,prompt 明示+測試);低品質回應=顧問行為(換問法/舉例)+標記交人審;每回合
LLM/工具呼叫**自建稽核落庫**;模型 role 沿 0026(interview=強、select/backstop=便宜)。

### Limitations(誠實記載)

- **單信息源**:v1=單一員工自述+顧問人審(人審=第二來源最小版);主管確認 pass、
  同職務多員工合併(O*NET/BEI 聚合本義)=路線圖。
- **純文字**:語音/視訊/情緒訊號=未來縫。
- 延後:書記並行化、self-consistency 投票、對話中 live critic、多子代理。

## 後果

- ✅ 對話自然(無格式負擔)+ 寫入零幻覺(strict enum+quote 驗證)+ 進度確定性(帳本),
  三者不再互相犧牲;RC1–5 資產全留用(executor/守衛/quote/select_schema/sim);
  與 0023/0024 無縫,0007 的 12-factor 原則落到位。
- ⚠️ 每回合 ≥2 次 LLM 呼叫(延遲/成本↑)——緩解:書記走便宜模型;序列版先量測,
  痛了才並行。
- ⚠️ 門檻數字是假設——緩解:pre-testing 制度化(sim coverage/depth 兩軸+黃金範本),
  上線前校準。
- ⚠️ 0025 第 1 點被本 ADR 修正,讀者須以本 ADR 為準(0025 內容不改,Nygard 慣例)。
