# Triage labels

Matt Pocock engineering skills 使用五種標準 triage 角色；本 repo 直接沿用相同字串。

| 標準角色 | 本專案狀態 | 意義 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待維護者判斷 |
| `needs-info` | `needs-info` | 等待提出者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要人工實作或決策 |
| `wontfix` | `wontfix` | 決定不處理 |

Skill 提到 triage 角色時，使用上表對應的本專案狀態。
