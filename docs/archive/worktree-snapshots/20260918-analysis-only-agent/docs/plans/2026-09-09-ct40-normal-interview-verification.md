## 固定員工事實（不注入模型，只作人工審核基準）

職位是依客戶需求開發／維護前端網站，非固定只做兩個網站。雲岸是課程報名網站，前端串接後端報名API及防重送，**不做金流**；青禾是會員訂阅網站，串金流狀態API、權限與付款失敗呈現，但後端處理扣款，員工無扣款／退款核准權。兩案不能混寫。每天排查客戶回報，每週五整理**所有專案問題**（不只付款）；上線前依驗收清單測手機／桌機、錯誤狀態及API串接，先測試站客戶驗收再配合上線。

初次員工說「印象中青禾需求變更由客戶產品負責人核准，但還沒核對」；後續查合約證實是客戶營運主管，產品負責人只彙整需求。只可在明確核實後改成確定。尚未談到的職責、案例或程序不能當不存在。更新核准者不得漏雲岸／青禾差異、頻率與無金流核准權。
