## Pass／stop

- 主訪談逐輪正常，背景非blocked；更正後同一事實不仍寫舊未知；兩案細節不互借；共通工作範圍、權責、頻率及低頻工作仍可找回。
- 不必將所有細節塞正文，但詳記／原話引用必須可沿路回查；無新增資料不自行補確定事實。
- 後段能辨認整份職位重要範圍已描述，不為不屬本人責任的未知無限追問。不據此宣稱100%完美JD或全職位統計穩定。
