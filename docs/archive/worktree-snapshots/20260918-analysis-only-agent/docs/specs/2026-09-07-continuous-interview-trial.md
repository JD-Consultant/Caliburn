## 試用步驟與判準

1. 角色與第一個案例：看是否簡短理解、提出有用的未知問題。
2. 根據AI問題補充責任、條件與頻率，不塞無關欄位。
3. 第二個相似案例：看是否分清共同工作與案例差異，無關瑣事不當工作事實。
4. 更正第一案：第二案與未更正細節不能跟著被改。
5. 重新開服務後回顧：保留更正、承認未知，不把單次耗時推為固定標準。
6. 若自然產生Memory且額度足夠，使用全新不带近期對話的reader回查；否則明示未驗，不以聊天回憶冒充Memory驗證。
