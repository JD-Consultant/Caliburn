## 6. 其他職位的文字適配檢查

以下是作者提出的反例檢查，不是已完成第二份真實職位驗收：

- **設備維修職位**：可以在工作條件寫實際搬運與輔具、操作姿勢及感官辨識要求，在任務完成要求寫安全隔離／功能確認；不必新增 A 分數，也不能把本前端例的電腦工作條件搬過去。具體要求仍要訪談及核實。
- **管理職位**：排定人力、資源配置、工作核准或績效回饋若是真實工作，應列為主要任務；「有管理責任」不能只藏在表頭，更不能因主管職稱自動推定招募、薪資或預算批准權。
- **單純或混合職位**：少量工作可少分組；兼任兩種不同工作也不能為湊單一主題而合併。是否用一份 JD 呈現兼任範圍屬具體使用情境，不由本例替所有人決定。

這些檢查支持內容骨架可表達差異，但不能證明所有職類都已測過。方法依據為既有證據表的 O*NET 工作情境／Abilities、NOS 條件與表現，以及 OPM 的真實工作分析，不新增體系。
