# 工作分析與 JD 內容的跨國證據

本表支援 [研究入口](2026-09-09-job-analysis-and-jd-content-research.md)、[欄位指南](2026-09-09-jd-field-and-writing-guide.md) 及 [分析指南](2026-09-09-complete-work-analysis-guide.md)。核查基準為 **2026-09-09**。以下區分官方直接事實、產品映射及公開資料不能證明的事；不是各國資料逐欄相等表。

## 1. 採證原則

1. 職務分析方法優先看職務分析主管機關、標準制定機構與實際發布系統。LLM 提示原則另看 OpenAI／Anthropic；它們不是職務內容的制定機關。
2. 「最新」區分網頁取得日、文檔修訂日、生效日及 PDF 生成日。沒有日期就明寫；舊而仍公開的原則不冒稱最新趨勢。
3. 職業通用標準、某個組織職位描述及某位員工實際工作屬不同範圍。職業資料中的常見要求不能直接寫成員工事實。
4. **多家相似原則是值得採用的證據，不等於所有細節被證明最佳。** 欄位是否單列、資料關聯與中文名稱仍須依成品用途決定。
5. 未取到原文、版本狀態不明或只看一個角色的結論，不外推為整體共識。本文以實際讀到的相關章節為範圍，不宣稱逐字讀完所有大型框架手冊。

## 4. 共同原則、可選方式、不能宣稱的共識

| 議題 | 多來源相近之處 | 差異／本產品仍須選擇 |
|---|---|---|
| 分析對象 | 工作活動、結果、條件及專業有關聯 | 職業標準、個別職位、訓練單元不是同一粒度 |
| 責任敘述 | 清楚描述工作，不僅貼個人特質標籤 | Duty／Task/CWF 名稱、層數與是否單列各不相同 |
| 成果與品質 | 需要理解工作達成什麼與如何判斷表現 | O 可獨立、內含或依情況省略；performance 欄也不同 |
| 能力 | 專業需求應與實際工作有關 | K／S／Abilities／Attitude 的縮寫不可直接等同；級別非共同刻度 |
| 成品資訊密度 | 有必要細節而不成冗長操作手冊 | 沒有本輪來源支持一個通用最佳責任數／每任務固定子項數 |
| LLM 方法 | 明確任務與限制、相關脈絡、適當示例 | 不同模型的最佳排序、輸出／推理配置與工具接法仍須分開確認 |

研究建議是以這些原則設計**完整分析、精要成品**。它不等於自己發明一套無依據的分類，也不能反過來把我們的十二項候選內容稱作各家逐欄共識。

## 6. 取得限制與不確定性

- National Archives 的指定 JD 頁無法取得正文；未用其搜尋摘要承擔結論。UK2 明確標為較舊實際雇主指引。
- Oracle Profile Types 原頁取得內容帶 Classic Talent Profiles／21A 遷移背景，不拿來當最新版設計證據；未將其加入候選架構。
- ESCO Knowledge 詞條回覆限流，未聲稱本輪已讀其定義；知識面向改由可讀的 O*NET／iCAP／NOS 核對。
- [OPM Six Steps checklist PDF](https://www.opm.gov/policy-data-oversight/assessment-and-selection/job-analysis/job_analysis_checklist.pdf)補查時可讀第1頁的資料蒐集／初步任務及能力清單；第2頁仍抽字異常，截圖及本地下載未成功（下載回覆403）。沒有完整核實六步，不以此宣稱評量篩選程序就是JD訪談流程；本輪深度建議另有下列直接可讀來源。
- SG1／SG2 關鍵表格由平行研究逐頁核查；主研究另核 SG2 第11–12頁文字。沒有宣稱讀完 645 頁每個角色。表格差異結論限於所列角色。
- AU3／AU4 只以該 R1 說明層次，未把版本狀態不明當現行強制要求。
- 本輪不宣稱「欄位齊全＝100分」。未說出的工作、員工誤記、模型錯誤及職位變動仍需訪談／確認；來源沒有提供自動保證。

目前資料已足以討論 JD 成品內容、完整工作分析面向及資訊取捨；不需要為同一原則再增加更多國家。Owner 已授權自主形成建議及完整樣稿，本輪補查集中在任務切分、完成要求、K／S去重及條件／權限的適用邊界，沒有重開完整跨國研究。具體效果見 [樣稿與審查](2026-09-09-jd-sample-basis-and-review.md)。

只有以下情況需再針對性研究：新用途／法域、某職類的特殊要求無法表達、兩個有效工作被錯合／漏掉、來源新版推翻重要依據，或後續真實使用顯示方法不合適。資料庫、框架、AI 編輯與 UI 屬下一層，不從本表自行定案。

2026-09-09 Owner 新提出「客製化樣稿是否不夠詳細」並委託補查，觸發下列§9：從職業標準補到實際雇主的職位分析／客製化指引。不是重開所有國家、Memory或模型流程；本題原則與選項已足以審閱，剩餘實際職位資料不能靠再找公版補出。
