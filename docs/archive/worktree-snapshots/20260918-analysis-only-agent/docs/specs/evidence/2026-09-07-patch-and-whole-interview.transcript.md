## 四、雲杉、海鷗、石橋與青禾案例的重要差異

### 1. 雲杉果汁機：有庫存的故障換貨

- 問題是無法啟動。
- 外部排查無法解決，技師確認為機件故障。
- 同型號有庫存，客戶選擇換貨。
- 員工安排取件、請倉庫核對退回商品附件，並寄出替換品。
- 原先估計三個工作日，實際第三天送達。
- 客戶確認收到且可使用後，才保留送達證明與回覆並結案。
- 客戶後續詢問兒童使用安全及清潔時，員工只依已核准的說明回覆，不延伸教導改造或使用非原廠零件。

**重點差異：**有現貨，因此可以直接走換貨與物流交付流程。

### 2. 海鷗除濕機：缺貨、補貨日期未確認，改由客戶選擇等待或退款

- 同樣是無法啟動，且外部排查未解決。
- 技師判定後原則上可換貨，但倉庫沒有庫存。
- 採購也尚未確認補貨日期。
- 員工不能為了安撫客戶而承諾到貨日期，必須區分已確認資訊與預估資訊。
- 改向客戶說明等待或退款兩個選項。
- 客戶選擇退款後，交由財務主管核准退款金額。
- 出納負責匯款；員工負責核對資料、追蹤匯款完成並通知客戶。

**重點差異：**不是有貨換貨，而是缺貨且沒有確定補貨日，因此核心工作是資訊界線、方案選擇及退款追蹤。

### 3. 石橋吸塵器：運輸破損，先依換貨規則處理，不等待物流求償

- 外箱凹陷、機殼裂開，屬運輸破損。
- 員工留存外箱與商品照片，交倉庫核對序號。
- 依現有換貨規則先安排更換，不讓客戶等待內部物流求償結果。
- 物流求償金額由物流窗口與主管處理。
- 員工不與物流協議賠付，也沒有物流求償核准權。

**重點差異：**案件重點不是技師判斷產品機件故障，而是保存運損證據、先保障客戶換貨處理，並把內部求償另行交由物流與主管處理。

### 4. 青禾電暖器：焦味安全風險案件

- 焦味案件不能沿用一般「無法啟動」的慢速詢問流程。
- 員工當天請客戶停止使用，在安全可行時切斷電源。
- 保存批號與客戶原始描述，立即升級產品安全窗口及值班主管。
- 依安全窗口指示安排取回及後續聯絡。
- 最終原因及處置由安全窗口確認，員工不能自行宣布召回、承諾賠償或解釋原因。
- 取回後仍不能自動結案，須依安全窗口確認內容通知客戶並留存紀錄。

**重點差異：**這是安全風險與跨窗口升級案件，優先性高於一般售後；員工的責任是安全初步處置、資料保全、轉交與追蹤，不是技術原因或產品安全結論的決定者。
