每月第一個工作日，你整理上個月所有售後案件的月報，不限於退換貨，也包括故障、破損、缺附件、安全疑慮和進度查詢。

你會核對並整理：

- 同訂單、同機器的重複詢問
- 客戶描述與型號
- 已採取的處理
- 技師判定
- 最終結果
- 尚未結案原因
- 代表性案例
- 「等待核准」、「已匯款」與「客戶確認收到」等不同狀態

資料不一致時，你會回查原案件或詢問承辦人，不為了讓數字好看而自行修改。看到某型號或現象集中出現時，你可以標示並提醒產品窗口，但不把統計直接寫成設計缺陷；原因判讀和改善方案由產品窗口等相關人員決定。

## 六、新人帶教與交接

休假前，你會把未結案清單、下一步、負責窗口和回覆日交給主管指定的代理人，而不是只留下「等待處理」。

## 七、目前清楚的責任界線

你主要負責的是**核對、記錄、依核准流程受理、溝通、交接、追蹤、提醒風險與整理資訊**。你有實際判斷，但判斷集中在：

- 案件是否重複

- 應依哪個核准清單或既有規則分流
- 哪些案件應優先
- 是否接近期限、需要更新客戶或升級主管

你不替其他角色決定：

- 技師的故障或責任判定
- 退款金額
- 物流賠償責任與金額
- 安全事件原因、召回或賠償
- 政策外方案是否核准
- 新人何時可獨立作業
- 公司的正式 KPI 或績效數字
