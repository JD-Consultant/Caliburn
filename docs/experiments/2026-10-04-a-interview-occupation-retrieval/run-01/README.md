這批結果不支持「初期資料不適合向量搜尋」或「A 訪談後放入更多原文一定更準」。倉庫與採購在同一人的第一則回答就已找到模型判為強代表的公版；完整訪談的四種方法都保留這些來源，沒有新增強代表。不同方法有局部名次改善及退步，不能只以原文字數選輸入。

## 來源與怎麼分段

三份既有歷史 A 真模型訪談：課程行政 12 輪、倉庫 12 輪、採購 45 輪，**員工均為合成人設**。沒有重新執行 A、生成更有利的回答、使用 JD 或 Memory 文字。也沒有全端工程師的完整訪談，不能用這批說後端漏搜已解決。

使用者選擇員工回答＋必要顧問問題。完整原文依時序保留全部員工回答；回答缺脈絡時保留前一輪顧問的最後問題段，排除寫入 JD 的敘述及末尾尚未回答的問題。問題只供理解，評分證據必須取自員工原話。未知、否定、更正及原回答的引號雜訊保留。

分段在檢索前人工按工作主題固定，原字拼接，不作 LLM 摘要：

| 案例 | 分段主題 |
|---|---|
| 課程行政 | 報名核對；課前安排／通知；出席紀錄／統計。 |
| 倉庫 | 收貨上架；揀貨補貨／搬運；盤點；退貨分工。 |
| 採購 | 需求／詢價／下單；交期／來料異常；供應商資料／評鑑；付款文件／進口交接；包材及年度協作等其他範圍。 |

每段沿原時序，並保留第一則回答的第一句作共同脈絡；主題名稱、輪次 ID 不進向量。同一回答涉及兩項工作可重用，每一整則問答在同查詢只選一次，分段聯集涵蓋全部 69 則員工回答。不過三案第一段同時放共同第一句及完整第一則回答，第一句各出現兩次；這個重複及事前「去重」措辭澄清另見[amendment](protocol-amendment-01.md)，原查詢未改。逐輪歸組與必要問題清單見[分段定位](segmentation.md)，原字及 start/end 見[queries.json](queries.json)、[cases.json](cases.json)。這是人工控制，還不是已驗收的自動 Memory 分段。

原話中的自報職稱保留，三份開場已含職務概述。因此這批不能被稱作「完全沒有職稱、只有零散工作內容」的測試；沒有另加公版名稱或預期答案。

## 完整訪談的四種方法

同一 805 份凍結公版、BGE-M3 1024 維、Qdrant exact cosine；各查詢 N20，員工全域去重 K5。R01 整段 dense；R02 整段＋rerank；R03 工作主題分段 dense＋RRF；R04 同分段＋rerank＋RRF。RRF k2，未設相似度門檻。公版職稱及 OPKS 代碼／表頭不進向量，正文及項目名稱保留。

3 強代表一個主要領域；2 部分代表；1 局部關聯；0 無實質代表。判讀看同一份完整員工事實與必要問題，隱藏方法、名次、分數及公版名稱；相同員工×公版共用同一分級。

模型判為 3 的來源只有三組：倉庫的「電商物流中心理貨員」「零售業倉儲管理人員」，以及採購的「採購助理」。它們各自在四法中都保留。多個 3 在同一領域不能相加成不同領域或 JD 完整度。名稱、正文證據及每份理由見[逐份報告](report.md)、[機讀結果](graded-results.json)。

## 評分疑義與核對

本輪33回應中31筆自動逐字引用驗證通過。J019兩處逗號後多空白、J025一處半形逗號變全形，三個引句均可唯一定位；只恢復來源字面，分數、理由及其他證據不變，沒有重評。[原失敗](grading-summary.json)、原31筆[judgments.json](judgments.json)、33筆分析版[judgments-02.json](judgments-02.json)及[修正紀錄](grading-reconciliation.json)分開保存。不能說模型33筆原引句均正確。

**語意分級仍需驗證。** H03「採購人員」已明確支持詢比價、下單、跟催、退換貨及請款，模型卻因公版另含採購計畫、招標、議約／合約終止等員工未承擔責任給 2；是否過度把額外責任當成降分理由，與「不要求整份公版皆適用」的界線尚未解。另一反例是 H03 對「倉管專員」的 2 分只引用同一句「通知存貨重新採購」兩次，仍未解釋為何孤立通知動作足以形成主要工作的具體子工作。保留原分，不按期待改分。課程行政只有2也不能直接推論全庫沒有適合來源。

沿上一輪七例的 7/7 只是同批規則回歸，沒有獨立評審或真人真值。本批三個不同職務，不能與上一批五個不同需求算訪談改善率；同人前後仍同時改變資訊量、必要問題、更正與重複，沒有拆開純因果。人工主題分段、共同第一句、自報職稱保留及單一模型評審均是限制。全端、真人、Memory、自動分段、全庫 Recall、ANN及 JD/PDF 收尾未測。

[機制核對](verification.json)通過69來源回答、18新查詢及真exact搜尋、360品質pairs、18組90個位置、33評審來源、54暖機trial／1080 fresh pairs；上一輪410封存原件未改。[獨立審查](review.md)另列機制與語意界線。自有Qdrant已停止，GPU容器已退出，權重／storage保留，未改正式App、commit或push。

下一個研究元件應先把「一組持續責任足以代表」與「公版額外責任」的評審界線測清楚，再比較保留工作主題與分工的整理表示。R01和第一則回答保留控制組；不能從本輪直接選正式相似度門檻，或斷言 Memory、更多原文、分段一定勝出。
