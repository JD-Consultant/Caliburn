## 真實輸入及成本

[B1／B2快照](snapshots/F01.json)保留title、description、body及固定來源關係。搜尋只取body，W合併、S逐原物件，不再切句。各案正文與查詢見[queries](queries.json)、[method-groups](method-groups.json)、[Memory統計](memory-summary.json)。H類Memory沿現行角色看完整合法歷史顧問答覆，原話控制只含原已固定的必要問題；沒有增加員工事實，這也不是等字數的純改寫比較。每案只產生一份最終快照，未驗連續更新或模型重複穩定性。

本機 BGE-M3、1024 dense、同一 revision／runtime、FP16、max8192，固定805篇公版整份。共93查詢，55個新unique文字實際embedding，最大1655tokens，沒有截斷；30份原話向量沿前輪。新embedding合計2.093秒，不含啟動／Memory生成，也不等於每員工端到端耗時。
