# B2與原話逐例人工複核（六例）

同一獨立核查代理，只讀原話與已發布B2；未看搜尋結果、未改標註或檔案，未操作模型/服務。

| 案例 | 核對的主要證據及結論 |
|---|---|
| E05 | seq2房況、進房及免打擾；seq4清潔自查、維修、督導放行、遺留物；seq6送用品、回報客訴及櫃台決策留存。未擴成部門管理 |
| E06 | seq2播種、環控/每日巡看；seq4核准調整、超限通報、隔離與出貨；seq6用藥/投資由負責人決定留存。未擴成經營或研發 |
| E07 | seq2備料定位與核准條件；seq4自檢、隔離、核准重工、品管判定；seq6工程確認、紀錄、管理排除留存。開工/收工時點留存，沒有猜日曆頻率 |
| E08 | seq2需求和觀察；seq4本人造型、安全停止及交付；seq6每日清潔、偶爾示範及非醫療/人事留存。未把示範擴成完整培訓或評核 |
| E10 | seq2團隊業務留為背景，seq4本人只確認參會聽進度，seq6對象/成果/頻率/權限未知。有非空B2仍不足判主要職位 |
| E11 | seq2觀測校正/分離模型，seq4科學程式/模擬/研究討論，seq6論文整理/疑問後重做留存。科研工作明確，未擴成商業軟體/營運系統/財務模型，也未把所有團隊成果及投稿決策算本人 |

六例未見會改變核心工作或決定權的實質缺漏/擴寫。一個Minor原樣保留：E06首段把每日巡看與記錄發芽率/處理接在同句，可能被讀成每日記錄；原話未明記錄頻率，末段已限定除每日巡看外頻率未知，應依此理解。

正例足以辨識核心工作，不能推論JD完整；E10資訊不足，E11是工作明確而805公版缺適當主要參考的不同負例。
