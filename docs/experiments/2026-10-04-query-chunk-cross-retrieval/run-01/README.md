# 員工工作分段 × 公版切塊：交叉比較結果

2026-10-04。**隔離研究已執行；未選正式檢索方案、相似度門檻或資料庫，未接 JD App。**

分段查公版chunk有局部效果：找回倉庫丟失的代表，保留冷氣的改善，採購多帶回一份既有模型判3的來源。但全端仍未找到強後端代表，還丟失整份全文搜尋原有的前端代表。因此目前保留**整段員工 × 整份公版**作控制，不能只用這輪選分段chunk為正式方案。

## 固定條件與十種方法

沿前輪五份固定合成需求F01–F05，以及三份歷史A真模型／合成員工訪談H01–H03。沒有真人員工資料，也沒有新的訪談／Memory。重用8個whole及22個人工工作主題segments，共30個原文查詢與原向量；H第一段共通第一句重複保留原貌。805父公版、BGE-M3 1024維及既有D/T/U向量全部沿用。

- D：整份公版，805point；只用max。
- T：單項任務及獨立overview，8068point；max或最高三個chunk的mean3。
- U：既有工作單元及獨立overview，3661point；max或mean3。
- W：員工整段一次查詢；S：各工作主題查詢各自搜尋，再依zero-based RRF k2融合。

各段有效候選為20份去重父公版，mean3只重排max的相同20父；最終每員工／方法全域最高五份。實際DB先取21父處理一例同正文的邊界同分，再按凍結向量cosine與父ID截20。完整失敗、診斷及差異見[取候選修正](retrieval-amendment-01.md)。沒有rerank、cosine門檻、按領域保留配額或D＋U雙路混合。

8案×10方法＝80組、400前五位置、103唯一員工×公版pair。95個pair沿用既有grade，8個新pair盲評；不使用grade決定排名。逐份0–3、不相加，不把同一領域多個3算成多個主要領域。[逐份報告](report.md)保存全部十法結果、名稱、理由與分段排名；[機讀結果](graded-results.json)保存完整候選及融合貢獻。

這是已評來源保留，**不是全庫Recall**。沒有grade3也不代表資料庫没有合適公版。

**全端的兩種失敗不同。** 分段×D仍在兩段初搜找到網站前端，分別第9、7，RRF後第6，被最終K5排除；分段×T/U則兩段都未把它找進各自N20，因此換融合規則不能直接救回該來源。十法前五沒有強後端代表；半導體軟體設計公版既有grade2，不視為後端已涵蓋。待區分語料不足、查詢表示或漏搜。[強代表逐段追蹤](strong-reference-trace.json)可查所有去留。

**倉庫的分段有用。** 零售倉儲在盤點段的T/U排名第1，讓S-Tmax／S-Umax／S-Umean3都找回整段chunk漏掉的來源；S-Tmean3仍在融合第6被排除。這證明局部段可以補候選，不代表每種聚合都能保住它。

**冷氣保留改善但增加局部來源。** 四種S-T/U均保留冷凍空調技術人員，但S-Umax新增的冷鏈倉儲得到1，只對應偶爾盤點工具材料，不能當冷氣主要職位。前輪W-Tmax的冷凍空調最高命中是overview，W-Umax才是工作單元5；不能把所有T改善都歸因於單項任務。

**mean3仍有取捨。** 會計助理由W-Tmean3第7回到S-Tmean3第5；視覺設計則W／S-Tmean3都丟失強代表。採購助理W-Tmean3第9、S-Tmean3第6仍未入前五。未比較其他RRF常數、候選深度或任務數偏差校正。

沒有新embedding或rerank呼叫。8個新pair同原F Prompt／schema、gpt-6-luna high、官方直接Responses，全部回應與逐字引用有效，估算 **US$0.005628700**；沒有改分或修正引用。先前sandbox的count連線失敗及一次自動審查拒绝保留；核實八個新job全為F01／F02／F04代理編寫合成文字、沒有歷史H訪談外送，目的地固定官方OpenAI後，審查接受相同命令，完成同批呼叫。[資料／目的地證據](provider-authorization-evidence.json)、[8次usage](judge-usage.jsonl)。沒有付費provider自動重試。

模型分級仍待校準。本轮兩份近似金融科技公版對同前端員工分別得到2／1，且理由的核心邊界不同；原分保留。前輪資材3／採購2的額外責任判準也未解。[具体疑義](grading-doubts.md)。因此逐字檢查通過只證明引用有效，不能證明模型分級正確。
