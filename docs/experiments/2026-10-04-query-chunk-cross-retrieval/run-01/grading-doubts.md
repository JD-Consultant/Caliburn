# 保留的語意評審疑義

沒有重評、改分或新增模型呼叫。沿前輪主要領域粒度、未負責的額外責任及一般動作1／2分界問題。本轮八個新pair均通過逐字證據檢查，但逐字有效不等於代表性分級一致。

新增具体反例：F02同會員網站前端工作，J001／FIS2511-001v2「壽險業-系統設計人員（金融科技）」得到2；J008／FIS2511-002v2「產險業-系統設計人員（金融科技）」得到1。兩份公版都含完全相同三句：

- 「從事網路平台規劃、建置、運行管理及優化」
- 「管理數位保險平台,進行後續優化改良,確保平台運行的穩定性與可靠性」
- 「重視使用者體驗,應用新金融科技優化保險商品。」

J001把平台建置、優化視為主要前端工作的一組子工作；J008認為相同概括內容沒有實質涵蓋版型、互動、API串接或瀏覽器品質。其正文不是逐字完全相同，但這兩個理由的核心1／2邊界不同，是待校準反例，不能逕自認定其中一分必然正確。原請求、回應、reason、grade、literal引用保留。

H03「資材人員」的3分沿前輪保留，但其額外庫存與專案責任未確認；和「採購人員」因額外招標／合約责任降至2的判準是否一致仍待驗。所以本輪可說分段把既有grade3來源帶回前五，不說已證明它比其他採購公版更符合。
