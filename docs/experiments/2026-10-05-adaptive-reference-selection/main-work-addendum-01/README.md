**目前證據支持修改評估目標，尚不支持把任一門檻採為顧問的自動追問規則。** 公版清單是候選參考，不能把每份的每個任務直接變成問題。主要工作是否存在、是否已被確認或否認，以及是否仍有實質缺口，須和檢索分數分開處理；這是待驗設計，沒有在本輪實作或宣稱顧問已少問。

## 證據範圍

- 仍是同一批 F01–F05、H01–H03 八案。F 組沿員工原話；H 組沿固定的員工回答＋必要顧問問題與角色標籤查詢。沒有新增員工案例。
- 已知面向由歷史盲評的 3 分公版 `main_work` 與案例原主要面向取交集而得。它是部分已知目標的回歸指標，不是人工全庫真值或所有未知工作召回率；H01 無已知 3 分，無法據此判定其涵蓋。
- 同一八案反覆比較參數，結果只在本 grid 與既有標註下成立，並非新 holdout、校準門檻或普遍最佳證明。0–3 是離線評分，runtime 沒有此標籤可直接篩選。
- CPU 重算已保存的選取結果；沒有 embedding、reranker、LLM、provider 或服務呼叫。配對數是工作量，公版數不是追問數；未測時間、真人體驗、否定回答效果或 JD 收尾品質。
