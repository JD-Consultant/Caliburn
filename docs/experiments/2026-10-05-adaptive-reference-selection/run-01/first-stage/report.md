## 分數門檻目前沒有顯示出可穩定取代候選深度的優勢

絕對cosine .675 對F01選103份，對H01選0份。H01在現有評判池沒有grade3，無法認定0份是正確行為；這也說明不能利用未評案例降低候選數後宣稱品質無損。D最高分跨案為 .6451–.7663，T為 .6680–.7521；同門檻不意味同相關程度。加前3保底後，這個門檻的DT候選增至297，仍保留12/12及8/8。

距最高分區間使用每query／每路自己的最高分，避免直接假定相同絕對尺度，但保留全部已知參考時本grid仍需至少588份。首次相鄰gap則容易在前段停掉正例，或找不到大斷點而幾乎取回全集；全保留的最小結果達6439，接近8×805=6440自然全集。這些結果支持繼續比較有界候選策略，尚不足以證明固定TopK普遍最優。
