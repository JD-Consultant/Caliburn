# 廣蒐與精搜共同選取的範圍補充

使用者於末端選取比較進行中補充：「廣蒐範圍也不一定要 topk」「多實驗找出最佳方案」。原 protocol 固定廣蒐只描述已完成的第一部分，後續擴充如下；舊分數、判讀及第一部分結果不改寫。

`first-stage/` 比較 D/T 各路完整805父排名的 TopK、cosine 下限、距最高分區間、相鄰落差及下限加小保底；包含不同兩路參數。事前 grid 及來源在該目錄，沒有新推論。

接著交叉初搜選法與已定69個末端選法，僅對整組8案所有被選 query×document 都有原 rerank 快取者重播。缺少任何配對時，保存缺少清單與原因，不移除該候選後冒充完整 rerank。初搜品質仍可由完整 dense score 及已知代表清單評判，但缺後段分數不能推斷最終品質。尚未評分的候選保留 unknown。

比較候選配對數、逐案已知主要代表及面向保留、0/1/2/3數量與未評數。以完整聯集247配對、末端40份作控制；候選配對數是工作量，非實測時間。動態數量不能證明顧問實際少問了幾題。上限10及完整池仍只是診斷。

額外跨案例檢查可每次用其他七案挑選：初搜不漏其已知 grade3，末端不多漏其原 Top5 的 grade3，無新增未評結果，然後依初搜配對數、末端0/1數、末端總數排序。套用剩下一案，列出不同參數及新增漏失。限制為快取完整組合、八案已被歷次研究觀察，非真正新資料驗證，亦不作通用最佳的證明。

所有結果仍為隔離研究。沒有重跑 embedding、reranker、LLM 評分，沒有服務啟停或 production 行為改動。
