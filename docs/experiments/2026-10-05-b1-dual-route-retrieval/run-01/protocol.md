# B1 雙路廣蒐比較協定

2026-10-05。使用者同意試驗 B1 情境查詢的整份＋任務雙路。這是隔離研究，沿用八個已觀察合成案例、發布 Memory、公版及本機 BGE-M3 1024 dense 向量；不接 production。

比較四種輸入：原話整段 O、B1 正文整合 B1-W、每個 B1 情境正文 B1-S、每個 B2 理解正文 B2-S。八案查詢數分別為 8／8／35／12。B1 單物件案例整合與逐情境相同，不當作獨立改善證據。公版 D 整份805、T 任務8068點（含803概述），每父以最高 chunk cosine 聚合。各查詢 D／T 各取20／40／80個不同父公版，完整聯集去重；員工候選再跨查詢聯集，不先融合截斷。

使用既有向量在 NumPy float64 正規化後新算 exact cosine；完整 point 分數、805父排名、候選及最低召回深度保存。20個 O／B2 查詢的40路完整排名須重現上輪；B1 的43個D查詢須重現原整份搜尋排名。這輪不重啟DB、不新增embedding、Memory、rerank、外部盲評或費用；不把離線計算時間當DB或App延遲。

固定採前輪158個已判pair中的12個grade3來源及8個已知主要面向，標註不變。7案有支持標註；H01課程行政的一個面向仍未評，coverage記null，不把空清單算100%。多媒體F05及資材H03兩份沿原疑義，另呈現排除敏感度。公版數與工作面向分開計算，不加總0–3分；不同查詢數代表不同成本，不宣稱等成本純輸入改寫比較。

保存96組初搜結果、逐query候選、公版去重數與query×公版配對數、逐target D/T名次與最低N、來源/程式SHA、控制核對、測試及獨立核驗。原凍結檔不改。尚未取得全805語意qrels、真人、新holdout、精搜前五品質及fresh服務延遲；只能判這份已知清單是否保留。

驗收：來源封存有效、全部83個控制路徑排名一致、各組候選逐項可重算、未知/疑義標註不變，並明列失敗與範圍。所有程式是本輪研究工具，不是產品元件。
