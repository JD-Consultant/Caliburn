# 顧問提問與員工否認的檢索反例

2026-10-05，事前協定。使用者要求測試：以主要工作為主；顧問提到某工作、員工答沒有，是否仍召回，甚至提高相似度。這是隔離研究，不修改 API 或 JD App。

固定三份合成主要工作（網站前端、日常帳務、倉庫作業），每案固定一個待確認範圍（SEO 策略／供應商詢比議價）。原文不由公版逐句改寫。各案比較原文、加問題、問題＋沒有、問題＋明確否認、問題＋有、問題＋不確定、重複三次問題與否認；另列人工已知的確認內容投影，文字與原文相同。投影是控制上界，不代表自動 Memory 抽取已成功。

全庫沿既有 805 份整份 D／8068 個任務與概述 T 向量。每份 query 新算本機 BGE-M3；CPU 精確 cosine，D20/T20 父公版完整去重聯集，不改現行控制參數。每案將所有變體候選及預先指定的主要／待確認公版合成共同 rerank 池，以相同公版正文逐一評分；同時回放每變體自己的聯集→Top5。共同池避免把候選集合變動混同為 reranker 辨別否認能力。

保存全部 query、向量、全庫 D/T 父排名、待確認任務 chunk 分數及全 T 名次、每份公版 logit、共同池排名及實際聯集 Top5。比較否認相對原文、問題、肯定的分數差與排名；分數上升與下降都如實報告。主要公版是人工預先指定的監測錨點，不是完整相關性真值；不以待確認公版含一個否認任務就判整份無關，不新增 0–3 評分。

僅使用已下載模型及既有 Docker 映像。容器 network=none、權重／原實驗／embedder 程式唯讀、只寫本 run；不啟停現有服務、無金鑰、無付費 LLM／provider。單次 GPU 執行最多 15 分鐘；失敗保存診斷，不改輸入後覆寫結果。用舊 F01 query 重算檢查與既有向量的最大差不超過 0.001。主要模型及來源檔 hash 全部記錄。

這輪能測搜尋行為，不能測顧問是否實際重問。已否認工作不重問、其他工作新增不重開、本人明確更正才重新判定、部分否認不封鎖整份公版，留作 consumer 後續行為測試。未知／拒答不能当成沒有做；否認不能刪掉「沒有」而留下任務詞。
