# 歷史實驗與工程證據

本區將舊工作樹中獨有的實測資料提升為可讀證據，不保留整套重複 checkout。它們是當時的實驗與反例，**不是目前產品的施工指令或最新驗收**。整理基準、去重後的保留位置與原件雜湊見[搬移對照](../../history.md#source-342210e06cceeff43952)。

| 材料 | 用途 |
|---|---|
| [analysis-only 的實驗報告](20260918-analysis-only-agent/reports/) | CT 系列的問題、提示／模型對照、長訪談、讀取路由、失敗與限制 |
| [analysis-only 的原始證據](20260918-analysis-only-agent/evidence/) | JD 編輯整合、Task6、模型輸入輸出、畫面與測試；失敗和修正一起保留 |
| [Memory routing 證據](20260918-memory-routing-spike/) | 回查、路由與 Memory 的歷史探測 |
| [R1 方法資產](20260922-local-main-r1/) | 原實驗的案例、提示、rubric、assembler、grader 與測試，非正式 App 程式 |
| [Agent 任務報告](../../history.md#source-61a65eccd9fae93aa608) | 實作切片的反例、修改、測試與未完事項 |

相同內容只留一份，個別結果可在[舊版實驗證據](../legacy-evidence/)或[原實驗目錄](../README.md)；不要因原快照位置已不存在就認為證據被刪。其他獨有歷史設計仍在[封存索引](../../history.md#source-e0ba6e4a9e510be1a900)，精確原版可由 Git 回查。

寫報告先讀[案例集](../../reports/research-casebook.md)，再按需查原件，不要求教授瀏覽全部 log。原始輸出、失敗、限制、當時方法與版本必須成套解讀；未跑的預期測試不算證據。
