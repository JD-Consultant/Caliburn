## 3. 主持人開始說明（可照讀）

「今天想了解這個 App 是否能讓你自己整理工作、看稿、修改並在之後繼續使用。我們觀察的是 App 哪裡需要改善，不是在考你，也不要求你會寫專業的職務說明書。

請用你自己能分享的工作資訊，不必提供公司機密或可辨識他人的資料。遇到不確定的事情可以直接說不知道，不用為了把畫面填滿而猜答案。

我會一次說明一個想完成的事情，先請你按自己理解操作。可以說說你正在找什麼、預期會發生什麼；我多半會先觀察。若卡住，可以告訴我，我們會記下卡住的地方；需要協助時也會記錄，不算是你的錯。你可以隨時暫停或結束，沒完成的部分會如實保留。

今天的紀錄方式是〔填入已告知的實際方式〕。你只會查看自己的文件。先請你簡單說說平常如何使用電腦，以及是否用過 AI 或整理過職務說明書。」

**主持紀律：**一次只給当前任務，不把下面全部觀察點念給員工。可按其實際工作調整稱呼，不能添加工作事實。先不指按鈕位置、工具名、順序或期待答案；不替員工回答顧問，也不叫他肯定模型。中性澄清可以問「你現在想做什麼？」或「你預期會看到什麼？」；一旦提供操作提示／代做，逐字及動作記下，該項不算自行完成。無須故意長時間讓人卡住。不要在同一場悄悄改 App/prompt 後覆蓋首敗。

## 4. 逐項任務語句與觀察（只對主持人顯示右欄）

以下是本案旅程映射；並非固定訪談問法，不要求每輪改稿。順序以當事人實際進展為準：沒有稿、沒有實際變更或無可用來源時，記未觀測／被前項阻擋，不假造內容使項目「完成」。員工只判自己意思、錯漏及操作理解；專業寫作與完整性評讀仍由原品質流程承擔。

|---|---|---|
| U01 開始／命名 | 「請在這個 App 開始整理你現在的工作，讓你之後找得到這份資料。」 | 如何找到入口、建立／命名、首次說明；是否要代操作。總計畫§5.5／品質§8建立。 |
| U02 自然訪談 | 「請按平常說明工作的方式和顧問談；問題不清楚或答不出來時，就照實告訴它。」 | 是否理解問題、術語／停頓／連續重問、能否說自己的話；不代填工作答案。品質§8訪談。 |
| U03 看稿／未知 | 「請看看目前整理出的內容，說說哪些是你的工作，哪些還不確定。」 | 能否找到稿、理解成果／要求及共享K／S；未知有無被誤認已核實。未產稿不能假稱看稿完成。品質§8看稿／全稿核對。 |
| U04 辨識實際變更 | 「請找出剛才這次整理實際改了哪些地方；如果你覺得没有改，也說說你怎麼判斷。」 | 以真 before/after／已保存版本核員工所指，不用聊天聲稱作證；找不到或無變更分别記。品質§8差異／歷史。 |
| U05 聊天更正／補充 | 「如果有與你意思不同的地方，請用自己的話讓顧問知道；也可以補充還沒說到的重要工作。」 | 員工實際更正原話、作用範圍、保存後是否正確、其他有效工作是否保留；沒有真誤解不要求編一個。品質§8更正／低頻。 |
| U06 直接手改 | 「請挑一處你想親自調整的文字，直接改成你希望保留的樣子。」 | 能否找到可編處、成果／要求是否各自保留、共享項改動影響能否理解；前景忙碌時能否理解可讀但暫不能手改。總計畫§1／§5.2及品質§8手改。 |
| U07 保存／狀態 | 「這一段先做到這裡。請讓這次的內容能在下次繼續使用，並說說現在有哪些已經留下來、哪些還沒有。」 | 以實際保存證據核判斷；dirty／送出候選／已保存稿、未知或錯誤有無誤報成功；不指示反覆重送。總計畫§5.3／品質§8未保存。 |
| U08 手改後續談 | 「現在還有想補充或討論的地方，請繼續和顧問談。」 | 是否找得到續談入口；手改仍在，無關內容未覆寫；不提示工具或要求模型照特定次序做。總計畫§5.2。 |
| U09 來源／歷史 | 「挑一段你想了解由來或以前寫法的內容，看看 App 能不能幫你找到。」 | 員工能否定位來源／舊版及理解其唯讀性；是否誤認另一份可編稿；來源可用性與員工操作分欄。品質§8來源／歷史。 |
| U10 暫停／取消 | 「如果你現在想先停下這次處理，請照你認為合適的方式做，並說說接下來你會怎麼繼續。」 | 僅當自然出現處理中狀態時使用；是否理解仍在處理／停止／結果未知。沒有窗口記未觀測；不故意注入全部工程故障。品質§8取消。 |
| U11 關閉／重開續談 | 「這次先到這裡。下次請從平常入口找回剛才的資料，再接著談。」 | 短時重開另記時間；誰做了什麼、只關頁還是新API程序、保存稿/原話/來源是否在；程序證據由觀察者填，不能從重開頁面冒稱新程序。總計畫§5.3／品質§8續談。 |
| U12 更名／切文件 | 「請把這份資料改成更好辨識的名稱；再另外整理一份你自己要分開保留的內容，之後回到原來那份。」 | 正確找回、未保存提示理解、不同文件內容無污染；第二份只屬同人，不看別人資料。總計畫§1／品質§8更名切文件。 |
| U13 封存／恢復 | 「有一份資料暫時不常用，但還要保留，請先把它收起來；之後需要時，請找回並繼續使用。」 | 能否發現封存／恢復而不提示按鈕；是否誤以為刪除；有未保存／執行工作時出口是否清楚。品質§8封存恢復。 |
| U14 全稿核對 | 「請最後看看目前這份內容。有沒有不像你實際工作的地方、漏掉的工作，或仍不能確定的地方？」 | 員工指出的錯漏／未知原話；不能要求評專業寫作分數或核准交付；不因畫面完成宣稱全稿已驗。品質§8全稿核對。 |
