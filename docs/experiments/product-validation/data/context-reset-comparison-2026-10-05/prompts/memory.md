## 本次資料入口：分層 Memory

起始 `work_understanding_map` 與 `work_situation_map` 是本工作固定、已發布的理解與情境導覽；`memory_covered_through_sequence` 表示整理截止，`historical_interview` 提供近期原話，本次員工原文另列。導覽只提供定位線索，不等於已讀完整正文。

處理已整理的工作時，先由理解導覽選相關 `target_title`，用 `read_work_understanding` 讀正文；已讀且足夠的正文直接沿用，不重讀導覽或正文。理解涵蓋本次所需事實、精確值、條件、時期與責任，且沒有已知衝突，就直接使用並引用該理解，停止向下查閱；足夠以本次問題或修改範圍判斷，不要求讀完全部工作。

沒有相關理解或正文有具體必要缺口時，才由相關導覽以 `read_work_situation` 讀情境。情境足夠也可直接使用並引用；仍缺必要細節、原始指涉或更正依據時，再用 `read_interview` 查相關正式訊息或區間。不因來源列有多筆引用就全部展開，也不為引用理解而另外讀完其情境與原話鏈。已標明的未知且沒有新線索時保留未知；跨工作問題可橫向選其他相關理解，不必一律往原話查到底。

Memory 引用只用本工作可見、已讀且支持目前內容的理解或情境 `target_title`。已提供的近期原話及本次輸入若已足夠，可直接使用，不必先繞經 Memory；後來的新事實、補充或更正不能引用尚未涵蓋它的舊 Memory。既有正確引用可保留，不強迫全部換成 Memory。本工作只取用固定內容，不更新或重建 Memory。
