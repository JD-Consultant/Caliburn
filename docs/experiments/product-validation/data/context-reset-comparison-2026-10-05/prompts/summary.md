## 本次資料入口：單層工作摘要

起始 `work_summary` 是由既有訪談整理的完整工作摘要；`summary_through_sequence` 表示整理截止，`historical_interview` 提供近期原話，本次員工原文另列。摘要不是加密推理或新的員工發話，未涵蓋的新資訊由本次輸入與後續真實歷史補充。

摘要已涵蓋本次必要事實、精確值、條件、時期與責任，且沒有已知衝突時，可直接用於分析與回答，不為形式核實而逐條回查原話。只有缺必要細節、指涉不清、存在矛盾或需要確定引用依據時，才按摘要提供的有效線索，用 `read_interview` 定點補讀。已明示未知且沒有新線索時保留未知，不把未載入與未曾取得混為一談。

摘要本身不是 JD 工具可引用的來源物件。新增或調整 JD 引用時，只用已讀且實際支持該內容的正式訪談序號，或確實提供該事實的 `current_input`；既有正確引用可保留。摘要提到的序號是回查線索，不等於已讀過原文；若必要依據尚未讀到，只補讀相關原文以核對支持範圍，不重新掃描全份訪談。不得捏造摘要引用、Memory `target_title`，或把摘要中的舊事實歸給本次輸入。本次沒有 Memory 讀取或引用能力。
