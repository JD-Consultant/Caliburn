# 導覽按需閱讀與短定位：36 次配對試驗

固定 Luna／high、合成資料、工具與事前判準，比較兩種資料提供方式及兩種工具定位表示。全部 36 個 outcome 已保存並獨立重算；兩次限流中止與其已呈報用量也保留。方法及續跑修訂見[protocol](protocol.md)，完整數據見[摘要](live-03/summary.json)、[逐次表](live-03/paired-table.md)及[CSV](live-03/metrics.csv)。

## 字串判準與語意複核

兩組六次都正確取得後續更正的頻率、期限、適用範圍，以及必要的兩個員工來源序號。全文組另外兩次沒有逐字符合：中段首次用「由我處理／部門主管核准／我本人沒有核准權」，末段第二次則在無核准權後補上主管決定的說明。

按需組六次的 authority 均有額外說明，沒有逐字等於答案「沒有核准權」，所以六次完整精確輸出都未通過。原分數不改寫。語意閱讀可區分未帶回標準字串與工作事實錯誤，但也發現第二次前段題將第一類的「1100 元」門檻寫進一般權限說明，沒有帶出該類限制；這份擴寫不能直接當成精準而完整的事實表示。

因此，本次支持按需讀取能顯著降低累計輸入，並提供關鍵更正及來源取得的觀察；不支持品質等價或「所有細節皆正確」的結論。下一次評估應先分開固定事實欄位與解釋文字，再以未參與調整的資料驗證，不事後放寬本批評分。

## 短定位的有效範圍

六種題目為單一目標、多目標順序、相近標題、延續先前工具選取、既存引用，以及一次預設的失效定位回饋。兩組都完整選取正確物件，未出現自發錯誤；短定位主要取得輸入及輸出表示的節省，不能由零錯誤樣本宣稱錯誤率優於 UUID。

兩組使用同一 `select_targets` 子任務工具，不執行正式 JD 修改。短定位回傳由 App fixture 映射到和 UUID 相同的物件位置；跨檔案與刪除後不可轉指等保存規則，另用[核心反例測試](../mechanism-checks-2026-10-04/README.md)檢查，不混作模型能力。

## 中斷、原件及用量

- `live-01` 完成前段兩筆後限流；第一次只記例外型別，不能回推其精確原因。
- `live-02` 承接未完成題目，保留中段兩筆結果；後段全文題在第二次生成收到 429／`rate_limit_exceeded`。安全 headers 記錄 200K TPM、剩餘 54,752 及 reset 43.574 秒。
- `live-03` 按實測 TPM 放慢發送，只補剩餘題目；繼承四筆 outcome（包含精確失分），沒有重跑或替換它們。各 manifest 記錄前段結果雜湊與累計預算。
- 全部共 58 次准入生成、58 次 count；56 次成功回應有 usage，其中一次屬於未取得終局答案的中止嘗試。36 個有 outcome 的試驗共 55 次生成。
- 含中止嘗試的呈報用量為 1,244,438 input／7,686 output、948,123 cached input、296,147 cache-write input；依公開四種 Luna 單價估約 US$0.05036。不是官方帳單，未將缺少 usage 的兩次拒絕假定為免費。
- 加密內容僅保留 SHA-256 及長度，公開 trace 不含原始內部推理或 API key；所以原件可核查輸入、工具及用量，不能原樣離線重送完整原生加密歷史。

限流等待隨續跑修訂而變，不能用本批端到端時間宣稱推論速度改善。所有組別都固定資料、題目及計分，流量控制只改研究發送節奏，不更動產品。

## 離線核查

```powershell
uv run --project apps/api --locked python docs/experiments/product-validation/data/design-comparisons-2026-10-04/analyze.py docs/experiments/product-validation/data/design-comparisons-2026-10-04/live-03 --include docs/experiments/product-validation/data/design-comparisons-2026-10-04/live-01 --include docs/experiments/product-validation/data/design-comparisons-2026-10-04/live-02
```

程式拒絕重複 trial ID 與不同凍結案例，逐筆重算原分數，另彙計中止前的成功回應；只產生衍生表格，不改寫原始結果、不呼叫模型。

複核曾發現同名 trace 的配對問題：中止題目在另一段續跑完成，彙總程式卻先找到較早的同名中止原件。已先用反例重現，再改為從 outcome 所屬 run 取用量；19 項研究程式測試通過。修正後完成題目的估價為 US$0.040449，含中止回應的總估價仍為 US$0.050359；答案、原分數及 input 降幅沒有改變。這是衍生費用彙總修正，不是模型試驗重跑。
