# 已整理工作是否仍需查原話：事後路徑核對（2026-10-05）

本批 Memory 組的一般工作題沒有再次查原話；唯一的原話呼叫用於追溯更正前的舊交付日。應優先改善的是已提供導覽的重讀，以及已讀細節在回答中的保留，不宜據此判定 B1／B2 未整理好。

這份文件依使用者後續確認的閱讀原則，分類已完成的 `live-01` 路徑，供下一批設計使用。它是事後分析，不重評、不刪題、不改原分母；[原結果](../results.md)、[凍結判準](../grading-cases.json)、[逐項成績](grades.json)及原始 trace 均保留。未新增真模型請求。

## 1. 原則與適用範圍

已完成整理的現行工作，應能用工作理解或情境支持一般分析；不能把 A 每次查回原話補救，當成整理完成的證據。原句、歷史舊說法與具體疑點仍可查原話；尚未整理的新輸入另行處理。

方法分別維護在[分析指南 §10.4–10.5、§12](../../../../../guides/2026-09-09-complete-work-analysis-guide.md#104-小範圍足夠深理解應能直接使用)及[讀取契約](../../../../../specs/2026-09-27-memory-read-and-source-navigation-contract.md#a-顧問的閱讀與停止條件)。本次只更新方法與驗收設計，未替換正式 Prompt、工具權限或發布流程。

## 2. 按問題用途核對既有路徑

下表依[逐題工具與用量](metrics.json)、[語意判讀](grades.json)及結果頁的 trace 定位整理。

| 題目 | 用途 | Memory 組實際路徑 | 能支持的判斷 |
|---|---|---|---|
| c01 | 現行收貨數量、入帳期限與權責 | 重讀理解 map，再讀一項理解；不讀情境、原話或 JD | 早期所需事實在讀回理解後取得，四項判準完整；map 重讀另有改善空間 |
| c02、c03 | 現行比率邊界、異常追蹤與責任 | 沿用已讀理解，沒有新工具呼叫 | 不必為每題重走來源鏈；這是同一段接續，不是獨立冷啟動結果 |
| c04 | 追溯更正前的交付日 | 讀「庫存報表」情境，再讀 #2、#42、#44、#48、#98 | 舊值只在 #42 原話，現行整理正文保留新值；此回查不是一般工作事實遺漏 |
| c05 | 新資訊：改為三／五工作日 | 讀 JD 導覽、任務，局部修改並引用當次輸入 | 新更正尚不在既有 Memory，不要求 A 用舊整理代替新依據 |
| c06、c07 | 包裝換算、已知未知、退貨時間 | 沒有新工具呼叫，沿用已讀資料 | c06 少說「資料窗口確認」，屬已讀細節的輸出遺漏；c07 有些資訊也在近期訊息，不全算早期找回 |
| c08 | 核對修訂後 JD | 讀 JD 導覽及兩項任務，不查原話 | 五項保存判準完整；不把這次複核另算一批獨立樣本 |

c04 的 Memory 路徑比摘要組多一次情境讀取及三則原話，這筆成本仍計入原總量，不因它屬歷史追溯而排除。來源列當時只提供訪談序號，不能假定模型已知道每則包含什麼，再要求它必須直接選中 #42、#98。

摘要組 c03 曾把摘要漏寫的採購決策權責說成「尚未說明」。那是摘要組的觀察；Memory 組同題正確，不把前者算成 B1／B2 的缺陷。

## 3. 如何定位真正需要修正的地方

後續遇到一般工作題必須查原話時，依序核對：

1. **先確認整理範圍。**事實是否已在本次 Memory 的涵蓋範圍？新補充或原句／歷史查證不能誤算整理失敗。
2. **比對原話與情境。**原話已確認的必要事實未被情境保留，追查 B1 的歸案、合併、去重或修訂。
3. **比對情境與理解。**情境已保留、且屬該理解必要工作條件，理解卻漏寫，追查 B2；個案經過留在情境不自動算缺漏。
4. **比對導覽與實際讀取。**正文有但選不到，查標題、描述、組織粒度及工具使用說明，不先重寫全部正文。
5. **比對已讀內容與答覆／JD。**已經讀到卻漏說、誤用或局部改寫丟失，查輸出要求及修訂方式，不把它當資料找回失敗。

工具仍允許例外查證；上述分類用於分析原因，不加第二套狀態、強制讀取順序或全量發布檢查。

## 4. 下一批最小驗證方向

先選已有反例的局部規則，固定同一份資料、JD、工具及判準比較，不同時重寫 B1、B2 與 A：

- 理解已足夠：直接作答，保留必要單位、責任及確認者，不重讀已提供的 map。
- 具體經過只需情境：選相關情境後停止，不展開全部訪談。
- 已明確未知：沒有新線索時保留待問，不反覆查同一批來源。
- 原句或舊值：容許沿引用查證，仍保留現行 JD 的規則。
- 已整理內容確實漏項：即使查原話後答對，也分別記錄回答成功與整理缺漏，不能合成「全部通過」。
- 當次新更正：使用新依據，只改受影響處，保留其他工作條件。

先比較答覆與保存品質，再比較查閱路徑、整段 input／output、時間及整理成本。一次呼叫較少或起始 Context 較小都不能單獨代表整體改善。

本批實證優先支持的兩個局部修正目標是 c01 的重讀導覽與 c06 的確認者漏說。尚無本批證據要求全面改寫 B1／B2。新真模型比較須另行凍結材料及取得費用／時間授權；本文件沒有啟動新一輪。
