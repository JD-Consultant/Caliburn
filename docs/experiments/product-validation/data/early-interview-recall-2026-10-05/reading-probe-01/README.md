# 導覽使用條件與回答限定：五對唯讀問答

本批支持兩項局部改進方向：**缺少導覽時只取需要的那一層；回答數值時保留影響解讀的確認責任。**十個獨立問答已完成，未改正式產品。新舊比較仍各只有一次樣本，不宣稱已消除偶發漏讀或證明整體成本下降。

## 1. 結果

| 題目 | 控制組 | 對應候選 | 判讀 |
|---|---|---|---|
| 已有完整 map，問早期收貨事實 | 直接讀一項理解；4／4 完整 | 同樣直接讀一項理解；4／4 完整 | 兩邊都沒有重讀 map；原本的偶發重讀未重現，不能宣稱已修復 |
| 沒預載 map，同一道收貨題 | 讀理解 map、情境 map，再讀理解；4／4 完整 | 只讀理解 map，再讀理解；4／4 完整 | 少取得一份當題未使用的情境 map，仍能找回資料 |
| 查更正前的舊交付日 | 理解→情境→原話；三項事實完整 | 相同路徑與來源；三項事實完整 | 沒把「資料足夠就停」誤寫成禁止歷史回查 |
| 問換算與未知保存年限 | 換算及範圍正確，但未說該數值已由誰確認；2 完整、1 部分 | 補回資料維護窗口確認；3／3 完整 | 兩邊都已預載完整理解，差異在回答保留，不是查回更多原話 |
| 只問每日進貨單張數 | 只答約 15–20 張 | 同樣只答約 15–20 張 | 沒有把細節規則變成每題展開整份工作 |

換算題的控制組並非不知道資料窗口：它說其他商品應交該窗口確認，但未連結到「此品號的 12 件換算已由該窗口確認」。候選明確補上這個關係。候選也多說了已知的文件存放與命名方式，雖非捏造，仍不是這題必需的內容。

[逐項成績](grades.json)共 15 項適用事實判準：控制組 14 完整、1 部分；各題對應候選 15 完整。歷史題原判準中的 JD 保存不在本次唯讀範圍，兩邊均未驗，沒有把「沒有 JD 工具」算成保存成功。兩種候選分開測，不能把這個合計當成已驗證的合併提示版本。

## 2. 用量與查閱差異

下表是每個問答從第一筆請求到最終答覆的總量，包含工具接續；不是只看起始 Context。Input 是 provider 回報值，含快取輸入。Output 含 reasoning tokens，不等於顯示給員工的文字長度。

| 問答 | 控制 input／output | 候選 input／output | 工具呼叫：控制→候選 |
|---|---:|---:|---:|
| 已有 map | 16,773／388 | 17,019／354 | 1→1 |
| 缺少 map | 21,517／779 | 19,821／474 | 3→2 |
| 歷史追溯 | 40,859／945 | 41,278／685 | 3→3 |
| 換算與未知 | 11,051／322 | 11,128／329 | 0→0 |
| 單一單量 | 11,017／61 | 11,094／83 | 0→0 |

缺少 map 那題的 input 少 **1,696 tokens（7.88%）**，與少讀一份情境 map 的路徑相符。導覽三題合計少 **1,031 tokens（1.30%）**；已有 map 與歷史題則因較長說明等差異略增，不能只挑下降那格宣稱全面省 token。細節候選每筆初始請求多 77 tokens，兩題總 input 多 154 tokens（0.70%），換來本次確認責任的較完整表達。

整批 22 次生成、22 次遠端 token 計數，input **201,557**、output **4,420**（內含 reasoning **2,501**）；本批無 compaction。耗時約 **101.3 秒**，按既有價格基準估算生成 US$0.014409010，加上計數預留 US$0.0022，合計占用 **US$0.016609010**。原累計 US$1.425661625，加上本批為 **US$1.442270635**；這是護欄估算，不是帳單。

## 3. 比較方式與證據範圍

- 兩種改動分開：導覽候選只改兩個 map 工具說明；細節候選只替換一段回答指引。固定 Luna／high、16,384 輸出上限、來源、題目與參數 schema。
- 每題成對使用相同新窗口；三道導覽題共用正式序號 101–105 的近期訊息及固定 map。缺 map 反例只移除兩份預載 map。細節兩題另預載相同完整理解，專測已讀後的表達。
- 原 trace 的加密推理內容已遮蔽，不能當原生歷史重播。本批沒有以假 reasoning 接續 c06，也沒有偷偷修訂 B2 正文。
- 只提供五項 Memory 唯讀工具；研究 adapter 依原始 105 則訪談及 13 個 Memory 物件回傳完整來源，沿用生成契約；沒有答案查表，沒有查詢正式資料庫。它不等於正式產品的 DB、JD 保存或恢復測試。
- 每個 episode 內按實際 response 接續完整原生 output 與工具結果。核對了 **12 次原生接續**；十筆初始輸入符合凍結請求，每次工具結果與原件投影一致，用量與 result 對帳一致。見 [audit.json](audit.json)。
- 判準在外送前保存，由工程助理逐項語意核對，尚未獨立盲評。c01、c06 是已見開發題，且每題只一對，不能據此推論所有員工、所有長度皆同樣改善。

這批結果適合用來選擇下一個小修改，而不是擴大重構：保留兩項候選，之後以正式 Context／工具組合驗收；本批不自行切換正式 Prompt。
