## 人設與資訊揭露

- 不知道的事：主管定的差異容許範圍未知。不自行填比例；顧問仍須能保留未知、換方向，而非循環逼答。

既有事實共 14 項：收貨驗收、上架、揀貨補貨、每日複點、月底盤點、未知差異門檻、年度盤點、搬運／環境、證照、客戶退貨、供應商退貨、掃描／錯儲位、旺季及責任限制。正式判讀逐項對照原件，不以關鍵字命中取代語意核對。

## 收束與品質判讀

依 [訪談深度與收尾指南](../../../../guides/2026-09-09-customized-jd-depth-and-interview-calibration.md)判讀廣度、深度、一致性、JD 雙向對照及員工核對機會。模擬員工的 `nothing_more` 只表示目前沒有補充，不代表顧問、JD 或整份訪談已完成。

結果分開回答：

1. **有沒有問出來：** 14 項事實中哪些由員工實際說出，哪些仍沒被問到。沒被說出的事不能歸為 Memory 或 JD 漏記。
2. **有沒有寫對：** 已說出的必要資訊是否保留；未知仍是未知，責任更正沒有擴張成採購或品保決策權。案例、旺季與一般工作不混為一談。
3. **依據是否成立：** JD 直接引用的已讀來源是否支持該項內容；Memory、情境及訪談的固定來源鏈可回查。引用存在不等於語意支持。
4. **公版是否有幫助：** 候選是否與已確認工作相關，是否帶來合理查漏或明確排除；不以查詢成功、候選數或分數當作完整度。
5. **能否收束及交付：** 顧問的收尾結論與剩餘問題相符，JD 已正式保存且可匯出；如仍有問題或達研究上限，記為未完成，不強迫給完成結論。

正式旅程與人工功能探針分開；執行成功、內容品質、成本與時間也分開。單一人設不能推導所有職位都能完整訪談或省時。
