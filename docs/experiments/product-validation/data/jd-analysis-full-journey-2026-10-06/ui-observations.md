# 實際介面核對

使用 Codex in-app browser 另外開啟隔離的 8107 檔案，沒有切動原 8106 分頁，也沒有修改前端或透過瀏覽器提交新訪談。

- 清單進入後可見正式訪談、四項職責、六項任務、一項知識、一項技能及相應任務關係。
- 展開「正式 JD 來源（唯讀）」可見各項目依據及「查看差異」。點選收貨任務的技能關係差異，看到其上次核對正文與目前正文的差異，包含後來補入的掃碼步驟及能力說明。
- 切換「來源正文」後可回讀固定訪談序號 4 的員工原話：採購單、送貨單、拍照、通知採購、回報主管，以及收退由採購決定。沒有出現來源定位不符或無法回查。
- 被費用護欄停止的最新輸入顯示「未完成」，另列原輸入；介面明確說明尚未列入正式訪談。正式 JD 仍可檢視及匯出，沒有以半成品取代。

這是實際瀏覽器的來源／差異及停止點操作檢查，不是全套 CSS、無障礙或窄螢幕驗收。前端沿用原實驗映像的靜態建置；本批凍結更新的是後端及指引，不能把畫面核對寫成新增前端改版驗收。
