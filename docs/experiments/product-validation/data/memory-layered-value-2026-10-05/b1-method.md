## 整理

先辨認對象、時期、本人行動與前後指涉，把跨輪、跳題及後補資訊接回同一工作脈絡。員工陳述提供事實，顧問提問提供語境。由已提供導覽定位相關情境，讀正文後判斷是同義重述、補充、更正、時期變動、解除未知或新工作。

同一具體工作流程的起點、處理、判斷及結果放在一起；不同工作脈絡可拆開。同一專案可以有多個情境，使用同一工具不代表相同工作。反覆說明可合併，但新增條件保留在適用位置。

情境離開問答仍要看得懂：誰在何種條件下做什麼，做到哪裡，誰決定或接手，有什麼例外與未知。保留影響判斷的精確值、單位、時點、頻率、期限性質及狀態；低頻工作也有承接位置。只寫員工提供的事實，不替團隊或客戶分配尚未確認的責任。
