# 分層比較的執行記錄

## 執行前

本批依使用者 2026-10-05 同意的 US$0.10／20 分鐘進行，正式產品及之前實驗不變。獨立審閱核對 109 個來源及 6 個輸入產物雜湊、18 則原話、三批上界與兩組相同的閱讀指引，未發現阻擋執行的問題。

完整原話組需要把「已預載」視為已讀，否則會被舊測試器強迫再用工具讀一遍。新增小型讀取入口處理這項差別，保留 Responses 原生輸出及 commentary phase；分層組仍使用既有 episode、工具 schema 和 V4A。沒有改正式引用權限。

測試記錄：

- 讀取隔離、已讀引用及原生接續四項先因未實作而失敗，再實作後四項通過。
- 防重跑及非授權目錄兩項先因未實作而失敗，再實作；Windows sandbox 的 pytest 暫存權限錯誤不算行為 Red，改用獨立暫存目錄與提升執行後才確認 Red。
- 三項完整編排／凍結檢查是事後補測，不稱 TDD。連同既有 workspace、protocol、episode、budget、completion schema，共 **31 項通過**。Ruff format／check 通過。
- `prepare`／`verify` 均不連網；`run` 先驗證凍結內容、exclusive 建立 started，再進入共用外送護欄。新分析腳本只投影原件，不改原件。

方法依據沿用本包 README 及其研究路由。本批重點是把已研究的分層整理方法驗成可觀察的保存、選讀與使用行為；沒有另造規則引擎、通用儲存或新的檢索服務。

## 結案方式

語意判讀以凍結的 grading.json 為準，保留正文摘錄與來源鏈。用量從 trace 的每次實際 response 計一次，不重算歷史中的舊 output；讀取正文、導覽及原話字元與 API token 分列。建立／更新成本不併入對照組，也不從整體成本中隱藏。

本批的結案數據與結論另見 results.md、semantic-review.md 及 live-01；本頁不事先宣告品質通過。

`live-01` 正常完成，無失敗、重跑或工具錯誤。獨立審閱完成維護快照 66 項正文及來源判讀，主審核對八份顧問作答；跨物件期限殘留與 JD 接手者省略均保留在[語意核對](semantic-review.md)，未手改任何模型產物。

結案時重新執行 31 項相關測試、Ruff 與範圍內 `git diff --check`，均通過。凍結來源／輸入雜湊仍吻合；離線接續核對通過，33 次生成皆有回應與用量。11 份相關 Markdown 共 172 個本機連結目標存在，另核對新增章節錨點。只更新分析指南的內容範圍／必要分工原則、研究接續結果與索引，沒有改正式工具、角色 Prompt、資料庫或服務，沒有 commit、push 或 merge。
