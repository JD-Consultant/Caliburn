# 分層 Memory 已能承接增量資訊，讓顧問停在理解層

2026-10-05，`live-01` 結案。四道題的分層顧問都只讀一項工作理解並引用，沒有展開情境或原話；期限更正、週期調整、核准人補齊與低頻工作均能由整理後的內容取得。這支持「先整理，再按需使用」的核心機制。JD 指定項目為分層 15／16 完整、完整原話 16／16；小型材料下尚未出現總 token 優勢。

## 比較方式

使用同一份 18 則合成訪談，依序提供三批資料：先建立工作認識，再更正早期資訊，最後補齊未知並新增低頻工作。B1／B2 從空白開始，各階段都操作同一套既有工具與 V4A。另一組不整理 Memory，顧問直接取得同時點的全部原話。兩組均為 Luna／high、同一閱讀指引及相同題目，每題各一次，沒有將評分或未來訊息放入 Context。

本批共有 6 次整理、8 次作答；共 33 次模型回應及 33 次 input token 計數。全部完成，沒有工具錯誤、失敗或補跑。14 個執行片段各由獨立上下文開始；片段內 19 次原生接續保留前次 reasoning 及工具呼叫／結果。未使用 Compaction，也未測超容量情境。[協定](README.md)、[接續核對](live-01/continuation-audit.json)

四題均直接引用已讀理解；情境、原話與 map 工具讀取次數都是零。來源鏈仍能回到支持事實的原話，不必為了引用逐層展開。完整原話組則分別預載 14、14、18、18 則訊息，可直接引用其中序號，沒有被強迫多呼叫一次工具。

## 2. 增量維護能沿用既有分析，但須管好重述的適用範圍

B1 情境正文與來源均保留 33／33 項；B2 理解正文為 31／33 完整、2 項錯誤，來源為 30／33 完整、3 項部分。差異集中在同一個問題：乙的理解多寫了甲的「24 小時」對照句，甲期限改為 48 小時後，這份跨物件副本沒有更新，也沒有綁定甲的來源。它沒有污染本批四份 JD，但不能因此視為已解決。[完整核對](semantic-review.md#1-三批整理結果)

這批同時留下可觀察的局部修訂：

- 初始兩項情境形成四項理解，分別承接兩種逾時工作及兩種交付後工作，不按整個專案各寫一篇理解。
- 第二批只更新兩項情境及兩項交付後理解；兩項逾時理解保持不變。
- 第三批只更新乙維護情境／理解，再新增一項低頻情境／理解；其他四個既有物件不變。
- B1 第三批一度只追加核准人答案，留下原未知句；同一次執行回讀後自行發現並替換原段，交給 B2 的最後快照已清除矛盾。這是實際工具迭代，沒有人工修改產物。

因此下一步不增加層或新元件：不必要的跨案數值對照不應複製進正文或導覽；必要的共同限定則保留並綁定支持來源。JD 整理仍須保留會改變責任歸屬的接手者。方法集中於[分析指南 §10.7](../../../../guides/2026-09-09-complete-work-analysis-guide.md#107-收斂後的整理與選讀準則)。

## 3. 完整成本，而非只看少讀幾篇

| 指標 | 分層建立／更新 | 分層顧問四題 | 完整原話顧問四題 |

| 模型回應 | 21 | 8 | 4 |

| 其中 cached input | 79,824 | 14,424 | 0 |
| Output tokens | 8,561 | 2,741 | 2,978 |
| 其中 reasoning tokens | 3,324 | 1,806 | 2,274 |

四題選讀理解正文共 725 字元；完整原話組預載訪談文字共 2,470 字元。然而分層還有導覽、工具 schema、來源描述和第二次請求，不能把正文減少當成總 Context 減少：本批閱讀 input 是完整原話的 **3.17 倍**。分層 cached input 較多，兩組閱讀生成費用接近；計入整理後，分層生成費用為 US$0.010850930，完整原話為 US$0.002312575。此材料很短，不作長訪談攤提或較便宜的證明。

整批付費階段 **518.04 秒（約 8 分 38 秒）**，其中紀錄的速率等待共約 329.84 秒。生成估算 US$0.013163505，另保守保留 33 次計數請求共 US$0.0033，故占用為 **US$0.016463505**；累計 **US$1.311735480／US$2**。計數預留不是帳單，也沒有未結算的生成請求。[用量、逐題選讀與物件變化](live-01/analysis.json)、[結案狀態](live-01/run-summary.json)

## 4. 收斂結論

本批支持保留既有分層：它能把跨批碎片整理成可單獨讀取、帶來源的工作理解，讓顧問不依賴全量原話也能作答。這不是「層數越多越好」或「每題只能讀一項」；只要理解足夠就停，缺口仍可往下查。

目前需修的是內容範圍與必要分工的保留，不是另換架構。新 Prompt、凍結輸入、快照、工具記錄、失敗檢查及語意評分都已留在本資料包；**正式產品指引未替換**。後續長訪談對照應再檢查正文、導覽及工具的完整成本，不能沿用本批小材料結果宣稱超容量優勢。本批不追加付費重跑。
