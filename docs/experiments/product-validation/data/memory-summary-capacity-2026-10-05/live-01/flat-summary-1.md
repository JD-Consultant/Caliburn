# 工作摘要（可延續更新）

> 本摘要整理截至本批訪談已確認的實際工作、分工與待釐清事項；不是職務說明書。來源以訪談序號標示。

## 一、角色與工作範圍

- 員工自述為**庫存與物流行政專員**，隸屬營運部，向倉儲主管報告。[S2]
- 已提及的主要工作包括：到貨登錄、庫存差異、退貨、缺貨追蹤、店間調撥及庫存報表；其中若干工作目前只有名稱，執行細節尚待補問。[S2]
- **工作邊界：**
  - 採購負責訂貨決策及議價；員工不自行決定訂貨、不負責採購議價，也不能更改採購單價格或自行同意接受替代品。[S2、S6]
  - 客服處理客人及退款；員工不負責對外承諾交期。[S2、S18]
  - 供應商實際何時補貨不是員工能保證的事項。[S12]

## 二、已確認的工作流程

### 1. 到貨核對與 ERP 登錄

- 每天約處理 **15–20 張進貨單**。員工比對採購單、送貨單與實際到貨的品號、批號、數量；實物由倉庫同事清點，員工核對單據並記錄差異。資料符合後才登錄 ERP，不可直接把供應商送貨單數量當作實收數量。[S4]
- 通常在**到貨當天下班前**完成已確認項目的 ERP 登錄。[S10]
- 月底最後一天由財務提供截止清單。超過截止或有疑義的單據，由財務決定歸屬月份；員工保留實際收貨時間及未決原因，不自行回填日期。[S10]

### 2. 到貨異常與追蹤

- 商品外箱破損或短少時，員工拍照、記錄實收件數及原單號，通知採購，並把未確認事項留在待處理清單。[S6]
- 員工更新差異清單及處理進度；**兩個工作日**未獲回覆時提醒採購，**第四個工作日**仍無進展時回報主管。[S12]
- 須待補貨或退貨完成且帳物相符後才結案；員工不承諾供應商實際補貨時間。[S12]
- 驗收不良件數占本批實際驗收件數**超過 5%**時，員工提報倉儲主管。**剛好 5%**不因這項比例規則提報；但如有安全疑慮，不論比例均先隔離並通知主管。[S8]
- 未確認：低於或等於 5%、且無安全疑慮的不良品如何記錄或處理，以及比例由誰核算，訪談尚未取得答案。[S9–S10]

### 3. 退貨核對與狀態登錄

- 退貨使用獨立清單。每個工作日 **08:35** 開始核對前一天收到的退貨，並在 **09:10 前**將退貨差異表交給客服窗口；此時限是退貨作業時限，不是進貨驗收時限。[S14]
- 核對客退單、品號、批號及實收數量。商品是否可再銷售由倉庫同事判定，員工依確認結果登錄為可售、待檢或報廢待核准；員工不自行判定報廢，待檢庫存不可列為可用量。[S16]
- 退貨數量不符時，員工提供照片及差異紀錄請客服確認；主管同意調帳後，員工才依核准資料更新 ERP，並保留核准單號。退款由客服與財務處理。[S18]
- 例外情形：外箱完整但內件不齊，仍維持待檢，不直接入可售庫存；主管請倉庫複檢後再決定處理方式。員工負責留下可追溯的狀態與紀錄，不以每筆立即恢復可售為成果要求。[S20]

### 4. 盤點與庫存差異查核

- 盤點分為平常抽盤與月底全盤：
  - 平常由主管指定高周轉或容易出錯的品項，員工核對 ERP 與現場清點結果。
  - 月底由倉庫同事分區清點，員工整合各區盤點表。[S22]
- 盤點有差異時，員工先查近期收貨、退貨、移位及待出貨紀錄；必要時請倉庫同事複盤。[S24]
- 不論差異大小，員工都不能自行把 ERP 改成現場數；必須有核准的庫存調整單。[S24]
- **尚未確認：**一般庫存調整單由誰核准；此處提及的核准單與退貨調帳須主管同意的流程是否相同，訪談未說明。[S18、S24]

## 三、已提及但細節待確認的工作

- **缺貨追蹤：**已列為主要工作，但缺貨追蹤的啟動來源、追蹤欄位、完成／結案條件及與採購的分工仍未確認。[S2、S11、S13–S14]
- **店間調撥：**已列為主要工作，尚未了解申請、核准、實物交接與系統登錄流程。[S2]
- **庫存報表：**已列為主要工作，尚未確認報表頻率、內容、提供對象及用途。訪談轉而說明盤點流程，不能據此推定報表內容。[S2、S21–S22]
- **一般庫存差異：**已確認盤點差異的查核與調整單要求；差異平時如何發現、除盤點外如何記錄／追蹤，以及調整單核准者仍待確認。[S7、S22–S24]

## 四、後續訪談建議回查

1. 釐清缺貨追蹤的實際觸發情況、狀態更新方式、結案條件與責任分工。[S11、S13–S14]
2. 釐清店間調撥的流程及核准界線。[S2]
3. 釐清庫存報表的頻率、欄位／內容、收件人及用途。[S21–S22]
4. 釐清庫存調整單的核准者，以及該核准流程與退貨調帳主管核准的關係。[S18、S24]
5. 釐清不良品比例未超過 5%、且無安全疑慮時的處理方式，以及比例計算責任。[S8–S10]
