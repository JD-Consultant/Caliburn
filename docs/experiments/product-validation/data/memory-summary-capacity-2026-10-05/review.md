- 空引用應拒絕：新增第六項反例，先看到`accepted != rejected`失敗，再加空引用拒絕與共同schema的`min_length=1`。有效Memory標題不代表正文已讀；不新增產品receipt或強制展開，改由最終人工判讀結合真實工具結果檢查。未讀正文的引用不得被歸因為成功使用該正文，來源支持另列。
