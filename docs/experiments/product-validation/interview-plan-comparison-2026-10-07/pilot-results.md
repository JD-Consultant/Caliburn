全批使用 80 次生成、175 次外送、1,690,141 累計 counted input；保守費率計算 US$0.057428625，結束 occupied 相同、retained reservations 為空。每個 admitted attempt 恰有一筆 received usage，80 個唯一 ID 無缺漏，input 共 1,396,686、output 共 59,724。資源停止原因為 generation attempt limit；P2 背景 Memory 結算為 7 completed／1 failed，沒有仍 active 的 execution。console 保留關閉 async stream 時的 `async generator already executing` warning；上述逐 attempt 核對未見本先導 usage 遺失，不能據此聲稱 warning 已修。正式遇未知 usage 仍 fail closed 並保留 reserve。

P1 沒有筆記工具或 plan 正文。P2 真工具包含 read 1 次（回傳 plan null）及 edit 9 次：第一次 numeric diff header 被 rejected／invalid_patch，之後 8 次 updated。模型先讀再用正式 patch 成功，回傳 diff 和後續真 HTTP plan 逐輪可核；最後公開 head 以「焦點：庫存盤點」開頭，含揀貨及補貨未知的最新內容。這證明 read／edit／保存接線，沒有跨換窗證據，也沒有證明漏項回訪改善。

先導包含兩個已送披露政策問題，原件不回寫：`b640e98e499f47e0a5496e7147b737aa` 對 oracle 未提供的新破損細節使用 known＋omitted，舊固定句可能暗示可再取得；`d7a6c0edf6b94ddd8e9616cb932a5616` 的純確認沒有問題，舊 mode 以 clarify 處理。正式新增 true unknown compound 片段及 no_question 分支；中性提醒不提供題目／oracle，最多兩次且不連續，仍無提問即共同收束並記未完整。其他題依實際相關性，只從 frozen facts 取原字串。沒有人工依輪次灌入盤點責任或其他重要工作。

準備但未 POST 的答案不列實際披露；blind 材料只取正式 HTTP employee originals。固定正文 preflight 用无 key 真產品 HTTP，依既有正式 revision／citation 讀 22／28 筆 interview 來源，沒有改用 latest Memory。離線另驗固定 Memory→情境→原話鏈及匿名 bundle 不含 arm、plan、graph metadata。

先導當時沒有逐檔原文 snapshot；事後僅恢復與原 manifest hash 精確相符的原文，詳各批 `archive-recovery.json`。兩批舊 `interview_plan_context.py` 由 root 恢復並核原 hash，paid pilot 舊政策、protocol、oracle、guard 及其他 production 原文均已封存。已改過且未先封存的 conditional_answers／manifest／run_batch／tests 無法聲稱完整復原；舊問題、decision、selected、POST 與工具原件仍可核。正式在出站前逐檔保存全部 frozen source（含依賴 lock）及完整公開 request，消除此證據限制。

正式校準生成 1500／外送 3500，仍維持 US$8／4h／16 compact／40M counted input／每場 20 Turn。這是根據先導機械消耗設定有限上限；兩組均沿相同界線，全結果與未排場次保留，不挑最好一場。
