# 工作分析與 JD 指南

本目錄的六份指南與樣稿說明顧問如何理解工作、訪談及撰寫 JD，提供分析方法、寫作示例與依據。資料結構、工具操作及產品流程由[現行規格](../specs/README.md)維護。

| 看一份具體成品及其限制 | [前端工程師樣稿](2026-09-09-frontend-engineer-jd-sample.md)、[樣稿依據與審查](2026-09-09-jd-sample-basis-and-review.md) |

## 接到產品與程式

- 哪些概念已成為產品要求：查[產品概念](../product-concept.md)與[目前決策](../current-decisions.md)。
- 資料、Tool、Context 與生命週期契約：查[現行規格](../specs/README.md)；程式實作依[開發規範](../implementation/development-standard.md)。
- 實際分析品質、失敗與修正：查[產品驗證資料](../experiments/product-validation/README.md)，不以指南寫好推導模型品質已達標。
