# A 訪談原文的四種職位參考檢索

使用者已要求以 A 訪談後原文比較原有四法，並選擇員工回答＋必要顧問問題；延續既有隔離研究，不改 production、不提交。來源是已保存的合成人設／真 A 模型訪談，不新增真人資料或重跑 A。

1. 凍結三類 A 訪談來源、必要問題與工作主題的原文定位；測前一輪問題對齊、未回答的末尾問題排除及顧問文字不可作員工證據。完整原話與初始第一則回答分開，評判始終看完整員工事實。
2. 固定同一 805 公版及 BGE-M3／Qdrant exact N20／全域 K5／RRF k2；完整原文比較四法，初始回答另外只作整段有無 rerank 對照。真初搜與離線全排名核對，保存 fresh rerank 與三次暖機計時。
3. 沿用上一輪 v2 Prompt／schema／Luna high，另外加說話者與更正界線；盲評所有方法的唯一員工×公版聯集，最多 US$1／100 回應，provider 失敗不重試。既有七例只是規則回歸，不當外部真值。
4. 逐份報分不加總，分開同員工初期／完整訪談、方法與成本；保存語意疑義、全部原件，唯讀核對與 reviewer，停止自有程序。不同職務與上一批五案不作改善比例；未測全端、真人、Memory 或完成判斷。
