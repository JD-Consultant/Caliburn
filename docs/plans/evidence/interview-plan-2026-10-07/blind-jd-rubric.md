# INTPLAN 最終 JD 匿名語意判準：2026-10-07

本判準先於正式匿名 bundles 固定，用於逐案檢查最終保存的 JD 是否有據、完整到足以辨識本人實際工作。它是本次比較的評閱證據，不是新產品 authority、不增產品欄位，也不以字數、任務數、欄位填滿、模型自報完成或筆記清空判定品質。

## 匿名邊界與方法

正式評閱只取得匿名代碼的 formal JD、已公開披露的員工原話及可回查來源。先完成各匿名案例的判讀與配對結論，再由主代理揭露組別；在此之前不讀 arm mapping、比較 harness 其他輸出、plan notes、tool usage、cost、模型設定或機制紀錄。評閱者不發 provider request，不因觀察模型成效調整 oracle 或本判準。

每案做雙向核對：有效工作資訊是否在 JD 有適當去處；JD 的責任、要求及專業主張是否真由公開原話支持。允許不同合理分組／粒度，不要求同一任務名稱、固定職責數或唯一正確文句。合併可避免逐案重複，但不能吞掉會改變工作判斷的差異；精簡也不能只留下通用動詞。

每個具體檢查點記為「足以辨識」「部分且影響判讀」「重要缺漏」或「錯誤」，附匿名 JD 位置、公開原話／source ref 及實際影響。合理不單列的案例細節不算缺漏。影響工作範圍、本人權限、專業判斷、交付、安全／品質或適用條件者屬 material；措辭美化與任務拆合偏好不據此判優。

缺漏另分：

- **已披露未入稿／錯合**：公開原話已有足以支持的內容，JD 遺漏、抽象過度、套錯範圍或與更正不一致。
- **重要工作尚未取得**：oracle 有重要工作或後續更正，但公開披露未取得。這是全場分析的查漏，不能把 oracle 直接補作正式 JD 事實，也不錯標成「公開來源無據」。
- **原話本身仍未知／拒答**：保持限定範圍，不補造細節，也不把不能回答寫成不存在或不需要。缺口可能限制成品可用性，但不能為填滿而懲罰如實保留未知。

「公開原話支持、但未取得 oracle 後續更正」與「JD 無公開支持」分開記錄。例如本人曾自報可決定新人上線，卻未再取得權限更正，前者有公開支持而仍有 material 責任查漏；不是無來源引用。

## 六維判準

| 維度 | 核對效果與反例 |
| --- | --- |
| 重要工作廣度 | 例行、周期、事件、維護／收尾、重要低頻與支援性工作均有合理去處。不能只整理最近一案，不能因職稱、公版未列或低頻而丟掉本人實際工作；不逐案堆重複任務。 |
| 本人行動、判斷與責任邊界 | 能辨識本人做哪段、看什麼決定下一步、何時請示／交接、誰核准。不得把協作升成全權負責，把團隊／主管／財務／品保／講師的工作歸本人，或以「妥善處理」遮掉必要判斷。 |
| 適用範圍、條件與更正 | 保留觸發、周期、對象、重要例外、環境／負荷限制與更正範圍。不能將單例或特定類型推成全部工作，不能因更正一部分而抹去其他仍有效資訊，也不能保留已被公開更正推翻的舊說法。 |
| 成果、交接與必要要求 | 能辨識形成／維持什麼、交給誰、何時算適當完成，以及已確認品質、檢查、限制與異常轉交。知識／技能須連回實際用途；不自造 KPI、時間、證照、學歷、權限或雇用門檻。成果與要求可分項，不能機械重抄。 |
| 無據內容與一致性 | 不以職業常識／參考資料冒充本人事實，不將過去、願望、偶然實績或未確定內容升為現職通則。任務、職責、目的、協作、條件與專業之間一致；未知不寫成已知或「不需要」。 |
| 來源保留與可回查 | 來源實際支持該主張且可回查，符合其身份、時間與範圍。引用存在不等於支持；來源多寡不等於品質。更正須保留必要的原話脈絡，未被推翻的有效事實與不同工作來源不能因重組丟失。 |

## 物流中心倉庫管理員的重要檢查點

以下是 oracle 層的預期工作，不是要求把未披露內容寫進 JD。各點都須標其公開披露狀態與適用範圍。

- **收貨與上架**：本人點件／品項數量外包裝核對，差異記錄與通知採購，按回覆登記入庫；不議價、選供應商或決定拒收。既定儲位、批號標籤、WMS 與實物一致；位置異常找組長，超重貨由有證照同事操作堆高機，不能推成本人必須有該證照。
- **揀貨／補貨及判斷**：波次、品項、數量、批號效期、包裝區複核；帳面有貨而儲位空時查移庫及前波次，不擅換批號。截單前完成及異常交組長，不捏造截單時刻。
- **盤點差異的剩餘未知與回訪**：循環盤點、查紀錄、複點、差異／原因表；主管核准、財務調帳，本人不能直接改庫存。更新後核對與找不到原因保留待查，不能把局部流程清楚當全部權限已知。
- **兩種退貨不能錯合**：客戶退貨依客服單核對、分類、隔離／待檢、可再上架入庫，本人不決定退款；供應商退貨由採購決定，本人備貨、核數量、出庫、承運簽收回採購，不是供應商退貨入庫，也不決定退貨條件。
- **帶教權限更正**：本人示範、安全動線、觀察漏掃／批號錯誤並留檢核；向組長回報，由主管核准獨立上線，反覆錯誤轉再訓練。若只取得最初自報批准能力，須記為尚未取得重要更正。
- **冷藏與旺季**：已披露時保留 2–8°C、早晚溫度檢查、防寒／隔離、時間溫度記錄、主管與品保通知以及品保決定放行；不能泛成單純倉庫環境。旺季順序按組長安排、不省批號效期核對，未完波次／缺貨／隔離貨位置須交班。
- **年度工作與未知**：年度全倉盤點、配合財務、整理儲位與待處理單據有工作意義；年度分區及表單細節仍未知，不補造核准／財務權限。
- **必要專業及職位定位**：已披露的效期／周轉／隔離概念、WMS／Excel 差異核對、重量與安全動線有實際用途。主管、工時／輪休等已確認條件保留；不能把採購議價、財務調帳、堆高機證照等外部角色要求移給本人。

## 成人教育課務行政專員的重要檢查點

- **排程與開課**：講師時間、容量、設備及撞期比對，課表草案交主任確認；衝突列替代與影響，不自行換講師或縮時。已披露時保留開課前兩天準備與當天提早半小時、設備找總務、換教室需同意，不能另造統一服務時限。
- **缺課後的剩餘交接與回訪**：本人記錄、按核准訊息通知；主任聯繫並核代課，而本人跟進教材、教室設備、重通知與課表；停課／補課沿主任決定，確認學員收到及留變動紀錄。不能停在「通知主任」便聲稱此責任已充分理解。
- **退費與收費資料邊界**：按日期、上課次數、收據及退費級距試算，補齊申請→主任核准→出納退款；本人追件、核狀態並通知，不核准例外、不經手款項。收費資料核對不能寫成本人收取所有學費。
- **報名與結業**：資格、名額、候補順序、缺件補正、收據與系統核對，爭議轉主任且不保證開課。點名／時數／結業名單交主任確認，成績由講師提供，本人不評分、不判定學習成果、不填過關。
- **評鑑、拒答與隱私**：匿名滿意度統計交主任；特定投訴／身份拒答不容補造或重開。權限系統、紙本鎖櫃、不以私人群傳全名單、密件副本／拒絕透露其他學員電話等已披露限制有工作意義；保存年限不確定，不能編年數。
- **低頻補助資料與未知**：年度出席、講師費、照片彙整，核齊備及日期，交主任結案；不是本人編預算／核銷。當年新增表單未知不能補造。
- **尖峰與假日交接**：先處理近期开課且資料齊的班、追缺件；假日和值班總務確認開門設備，收回點名／異常及交主任未結事項。相應條件不能泛化為所有工作都同一期限。
- **必要專業與定位**：報名、退費、出席門檻、系統／Excel 核對、排程比對、清楚通知與確認收到、釐清不滿及權限外承諾轉主任有工作用途；不以學歷／證照或通用能力清單填滿。

## 每案結論與配對比較

每案以「有據且可用」「仍有 material 缺口／錯誤」「尚無可用成品」作有理由的質性結論，列出重要已涵蓋、重要未涵蓋、責任／條件失真、無據主張及來源問題。有限資源停止而尚未形成可用成品明記未完成；模擬停止、拒答或自然結束不自動算完整。

匿名配對只依相同工作事實的重要差異判斷：哪份更完整且有據、哪份有 material 退步，或無可辨差異／各有得失。不為單一重要漏項造綜合分數，不將更多字／任務／細節當優勢；新增無據細節亦不能抵銷缺漏。

此 final-JD judge 不評工具次数、成本、筆記內容、compaction 接線或不必要追問。是否自主返回取證、披露是否遵守政策、機制／費用與代表性重現，由主代理在盲評固定後另行核對。本判準寫成時尚無正式匿名 bundles，沒有產生案例結果。
