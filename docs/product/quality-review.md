# 職務分析內容評閱

本頁將產品內容判準轉成逐項可觀察的評閱問題，不是模型通過紀錄或已校準的自動評分器。實際輸入、輸出、引用與正式保存須一起核對；內容要求以[產品概念](concepts.md#內容判準)為準。

每個適用維度標 `pass`、`partial` 或 `fail`；階段沒執行或證據不足標 `not_observed`，不能當成功。每項保留可定位的原話、結果及理由，接受語意等價的分組與工具路徑。

| 維度 | 核對內容 |
|---|---|
| 事實與更正 | 是否區分新舊範圍，避免把推測、顧問問題、人工稿或公版當員工事實。 |
| 責任與條件 | 本人／團隊、日常／月底、特定案／全部、目前／歷史／願望是否清楚。 |
| 未知與廣度 | 是否保留未確認範圍，避免一成案例就宣稱整個職位完成。 |
| 有效工作保留 | 低頻重要責任、其他案件及未被推翻的舊工作是否保留；沒再提不等於撤銷。 |
| 粒度與精簡 | 是否讀得出工作、對象、判斷、結果及條件，避免工具名當任務、逐案重複或整段抄原話。 |
| 引用與正式效果 | 來源是否真實支持主張，實際 JD／Memory 是否與宣稱一致，不能只看最後答覆或工具成功。 |
| 顧問引導 | 是否針對有影響缺口中立追問；已知先回查，答不出可保留，不逼猜、不每輪硬改。 |
| B1／B2 分工 | 情境承接背景、方法、數值及來源，理解保留必要條件；不跨角色改寫或強造每案理解。 |
| Plan 接續 | 已答不重問、待入稿／核對仍保留、完成微步驟移除；空計畫不等於成品完成。 |

無據責任／標準、錯範圍更正、關鍵工作遺失、錯誤引用／資格、未知升確定及宣稱未保存的效果，均為重大錯誤，不能用平均分、流暢文字、較少工具或 token 抵銷。沒有重大錯誤但遺漏必要細節可標 partial；純措辭差異另註，不鎖唯一答案。

評閱同時看正反方向：缺主語應釐清，資訊充分則不必重問；可先寫有據部分，也可保留準確無變動的稿；一次事件可留情境而不升為固定職責。核對整份 JD 的共用項目及關係，不能只看單一任務。

比較先固定資料、可見範圍、基準與候選。預期答案及未發生材料只供評閱，不交受測模型。抽取成功、失敗及爭議例作獨立人工複評，保留分歧；無人工校準時明示待評。樣本與限制、模型外送及費用沿[模型品質比較](../../CONTRIBUTING.md#模型品質比較)。
