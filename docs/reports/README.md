# Caliburn 團隊報告與研究材料

本區面向產品評閱與研究讀者，解釋團隊的設計及實驗成果。各報告按自己的整理日期、受測版本與範圍閱讀；本索引涵蓋整理至 2026-10-06 的報告，現行工程規則仍由[目前決策](../current-decisions.md)與責任文件維護。

## 產品介紹與報告

1. [產品介紹](../product-introduction.md)：顧問作業需求、使用流程及產品價值。
2. [團隊專題報告](project-report/report.md)：問題、方法、設計、實驗與結果；章節選讀見[閱讀指引](project-report/README.md)。
3. [系統架構報告](system-architecture/README.md)：按報告版本解釋 Context、Memory、JD 引用、保存與恢復，附[架構圖](system-architecture/diagrams/README.md)。

[四分鐘產品影片腳本](product-demo.md)仍屬錄影規劃。
