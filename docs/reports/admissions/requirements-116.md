# 116 學年度資工碩士甄試要求核對

查核日期：2026-10-02。以下截止時間均為臺灣時間，民國 115 年即 2026 年。優先目標為成大資工甲組；臺大與陽明交大先保留跨校準備差異，尚未代選其組別。送出前仍須核對官方更新與實際報名系統。

## 成大資工甲組

一般生代碼 691。依[116 學年度校級簡章](https://adms-acad.ncku.edu.tw/var/file/44/1044/img/375725349.pdf) PDF 第 2、8、27 頁（資工為印刷頁 22）：

| 作業 | 截止 |
|---|---|
| 報名登錄及繳費帳號取號 | **10/5 12:00** |
| 臺銀臨櫃繳費 | 10/5 15:30 |
| ATM／信用卡繳費 | 10/5 16:00 |
| 資格與備審上傳、推薦人建檔及寄出系統通知 | **10/5 23:59** |
| 推薦人完成推薦函 | **10/6 23:59** |

各項上傳限 PDF、5 MB。甲組審查及面試各 50%；審查優異者得免面試，最多該組名額三分之二。乙組「資訊能力占書審 70%」不適用甲組。

指定審查分類為：成績與排名、資訊能力、專題／研究能力、外語及其他能力、簡歷與讀書計畫、考生個人審查資料，以及兩封系統推薦函；另有校級身分／學歷資格文件。這些分類不代表人人必須已有論文或獎項。查閱範圍未見專題報告固定頁數；外連表單內要求仍須核對。

[系辦 2026/9/9 公告](https://www.csie.ncku.edu.tw/zh-hant/news/13573)另要求完成指定考生表單，將填妥截圖上傳校級系統第六項，不是另放一份自製個資表。其連到的[資料表](https://forms.gle/q2MBs6HvzcB7KKHh7)尚未代填；第二階面試名單須留意系網。

### 送出前逐項核對

- [ ] 已登錄、取得繳款帳號，並確認繳費成功。
- [ ] 資格文件與備審各項皆已完成，不把其中一項上傳成功當作全數完成。
- [ ] 成績及名次證明版本正確；無法提供的文件依校方規定處理，不自行補造。
- [ ] 已在系統邀請兩位推薦人，告知其不同截止時間並自行確認回覆。
- [ ] 系辦資料表完成，截圖放第六項。
- [ ] 每份 PDF 未超過限制、可正常開啟，個人貢獻與成果限制寫實。

勾選須以申請者實際操作為準，本頁目前沒有確認任何一項已送出。

## 臺大資工一般生

依[116 學年度系方公告](https://www.csie.ntu.edu.tw/zh_tw/Admission/Announcement13/-16291570)，採資料審查 100%；需學歷／在學證明、成績、名次、系方個資表、就學計畫及有利審查資料。研究報告、著作及競賽可放後者；推薦函非必繳，最多三封，由推薦人上傳。

校級登錄／繳費日期至 10/7；系方個資表及資料上傳至 **10/8 17:00**。登錄／繳費的精確時刻仍須校級簡章核對，不能把 10/8 當作開始報名期限。系方表單須填後下載再上傳，仍要完成校級報名。

## 陽明交大資訊相關所

依[116 學年度資工系招生公告](https://www.cs.nycu.edu.tw/announcements/detail/14303)，有校級與資訊學院兩套系統，都要完成。考生填寫／上傳與寄推薦邀請至 **10/7 17:00**；兩封推薦函由推薦人於 **10/12 23:59** 前回覆。

多人合作專題／競賽須交代全組貢獻比例、總和 100%，並由指導教授簽名。這是該公告要求，不移植成成大甲組明文規則。資科工不同組、資訊聯招、AI 等仍有各自分則；未確認報考組別前，不共用一份完整必繳清單。

## 共用與不可共用的部分

問題、設計、實驗與限制沿[共用案例集](../research-casebook.md)整理一次；各校再調整表單、文件組合、研究契合說明與篇幅。三校均不能用專題取代成績、資格及正式程序；同一專題也不能因換校就改變數據、誇大個人貢獻或隱去失敗。
