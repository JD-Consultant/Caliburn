# 從系所與教授公開資料看：哪些材料能呈現研究潛力

查閱日：2026-10-02。優先對應成大資工甲組，並參考臺大、陽明交大資工公開資料。這份文件用來**決定找什麼證據**，不是錄取預測、官方評分表，或替申請者認領專案成果。

主要判斷是：不要只展示完成的 App，要讓讀者看懂**遇到什麼問題、如何形成判斷、用了什麼方法、結果支持到哪裡，以及本人參與了什麼**。這是以下資料的綜合推導；各教授的研究方向與偏好仍不同。

## 2. 以審閱者角度，材料應回答的問題

下表是**本次整理判準**，不是教授原話或官方評分標準。研究所是在培養研究能力，材料要呈現基礎與可培養性，不需要把工程專題誇大成已完成論文貢獻。

| 能力面向 | 可用來檢查材料的問題 | 優先找的證據 | 單獨不足的材料 |
|---|---|---|---|
| 基礎與實作理解 | 為什麼這個資料結構、演算法或一致性邊界合理？失敗反例是什麼？ | 能解釋的程式、資料關係、複雜度／資源分析及反例；另配修課資料 | 框架清單、程式行數、測試數量不能代替基礎理解 |
| 問題定義 | 原方法到底在哪個情境不夠好？是使用者需求、資料、模型還是接線問題？ | 當時輸入輸出、試用回饋、錯誤定位與排除過程 | 只寫「向量不好」「LLM會忘記」而無場景 |
| 文獻與來源判讀 | 查到的研究支持哪一步？有哪些不同條件或反例？ | 方案比較、原文定位、修正誤讀、拒絕不適用的建議 | 連結很多、用了大廠做法，不等於理解或有效 |
| 抽象與系統推理 | 如何由具體問題得到可維護的模型？為何不做更複雜方案？ | 責任／資料模型變化、替代方案、行為不變式與限制 | 架構圖漂亮或一直重構，不自動證明設計較好 |
| 實驗與驗證 | 如何知道改善來自這次改動，而不是換資料、改評分或偶然？ | 同條件基準、反例、原始輸出、指標定義、評分複核及失敗結果 | API成功、單次滿分、不同條件前後對比不能直接當因果證據 |
| 自主判斷與修正 | 結果不支持原想法時做了什麼？何時停止試錯？ | 未採用方案、翻案、限定結論、停止無效試次的理由 | 熬夜時數、重試次數、AI對話量不是能力證明 |
| 溝通、誠信與協作 | 別人能查到並重現嗎？本人、AI、他人分別做了什麼？ | 可追溯材料、清楚圖表、工作分界、未解問題及資料使用範圍 | 自動生成報告不能證明本人能口頭解釋；Git作者欄也不足以界定實質貢獻 |
| 研究方向的延伸 | 現在還不知道什麼？下一個問題怎樣被驗證或推翻？ | 從已知限制提出有範圍的問題、比較對象與觀察指標 | 「未來導入更強模型」或堆更多功能不是完整研究問題 |

對 Caliburn，值得找的不只有最終 Memory 架構，也包括**最早 PDF／資料品質、檢索失敗、訪談方式、領域方法、錯誤評分、編輯契約及取捨**。具體入口見[按能力找證據](../development-history/evidence-by-capability.md)；時間先後仍由[原演進索引](../development-history/README.md)維護。

## 3. 怎樣留下材料，才不會事後編故事

每個候選案例先保留以下資訊，不急著寫自傳敘事：

1. **當時的問題與材料位置**：可點回原文、輸入輸出或固定提交，避免只靠回憶。
2. **當時知道／不知道什麼**：區分觀察、推測、外部建議及已驗證結果；不把後來答案倒灌到最早版本。
3. **做了何種判斷**：方案如何比較、為何改或不改；普通框架整合不冒稱新演算法。
4. **證據與反證**：成功、失敗、撤回及不確定結果並列；實驗條件不同就明說。
5. **個人參與待核實**：哪部分由本人提出／判斷／驗證，哪部分由 AI 或協作者完成；缺資料先留缺口。

材料可分成：**有原始輸出的實驗證據、可核對的程式／測試、只有當時報告的結果、尚未驗證的設計或研究建議**。不是替故事打分，而是防止把「有測試程式」說成「本次跑過」，或把研究推薦說成效果已證明。

## 4. 目前還不能由 repo 補出的部分

- **本人基礎與分工**：成績、修課、個人思考、指導／合作關係仍需本人提供。尤其 AI 協作密集，應挑能親自解釋問題、方案與反例的部分，不宣稱全程獨力手寫。
- **真實使用成效**：合成人設或樣稿不等於真人員工與職務分析專家的驗證；不能據此宣稱已減少多少訪談工時或普遍優於顧問。
- **研究新穎性**：多次優化及成熟機制整合可以支持工程分析過程；要主張學術貢獻，仍需相關工作比較與相應實驗。
- **適配性**：本專題目前可從可靠AI系統、軟體工程／資料證據、互動訪談等角度談，但是否適合某位老師，要另外讀其研究，不由產品名稱直接配對。

因此，本階段先擴充可查證材料池，**不限制只剩兩個近期成功案例，也不把所有材料都塞進備審**。後續再依本人貢獻、證據完整度、申請方向與篇幅挑選。
