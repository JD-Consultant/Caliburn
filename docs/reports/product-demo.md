# Caliburn 產品影片腳本

狀態：錄影規劃，尚未拍攝。建議成片約四分鐘，以正式產品及合成訪談資料展示；實驗數據依[專題報告 §5.9–5.10、附錄 B.15](project-report/report.md)呈現。

本腳本供團隊介紹共同成果，整理日期為 2026-10-06。錄影前核對實際執行版本：先前 Docker 示範映像尚未包含最終刪除收尾防護，公版工具也未在該示範設定啟用，見[示範更新](../experiments/product-validation/2026-10-05-docker-demo-update.md)與[刪除驗證](../experiments/product-validation/2026-10-05-job-file-deletion.md)。

## 影片要讓觀眾看懂的事

員工描述工作，AI 顧問逐步釐清並形成 JD；讀者可回查已保存的來源，後續補充可以修訂既有成果，最後交付可閱讀的 PDF。畫面以產品操作為主，不講資料表或工具參數。

## 四分鐘主線

| 時間 | 畫面與操作 | 旁白重點 |
|---|---|---|
| 0:00–0:20 | 題名後直接進入已有訪談與 JD 的職務檔案 | 「Caliburn 讓員工透過訪談說明實際工作，由 AI 顧問逐步整理職務說明書，並保留形成文件的依據。」 |
| 0:20–1:10 | 一段員工補充、顧問釐清或修改，以及右側相關 JD 項目；若採既有成果回看，標示為訪談紀錄 | 用一項具體工作說明：工作量、期限與誰決定都會影響任務敘述，不只把職稱展開成通用職責 |
| 1:10–2:00 | 從 JD 的真實來源標籤展開已引用的工作理解，再依現行介面往下查看情境與原話 | 「整理後的理解可繼續使用；需要核對時，仍能回到具體情境與員工當時的說法。」 |
| 2:00–2:50 | 展示一項局部修改及其待核對差異；對照未變的相鄰項目 | 「新補充不必重寫整份文件。系統保留原依據與差異，讓顧問判斷該修什麼，以及哪些條件仍有效。」 |
| 2:50–3:25 | 查看 JD 全文並匯出 PDF，打開實際產出的檔案 | 「訪談、分析、修訂與交付在同一份職務檔案中延續。」 |
| 3:25–4:00 | 回到產品畫面，疊上兩張簡單成果字卡 | 「同一 Memory 的三對共同完成測試，33／33 項核心事實保留，讀取 23 → 3 次，累計輸入少 56.2%。另有早期數值找回與 JD 局部修訂的接續實驗。」 |

成果字卡須標示「合成案例、相同 Memory、共同完成三對的核心事實與閱讀指引對照」，不把閱讀策略的降幅寫成所有訪談或三層相對摘要的普遍降幅。影像中的產品成果與字卡中的比較實驗分開標示；這批閱讀指引對照與正式 B2 兩句提示的局部採用也是不同變更。

## 選擇錄影資料

優先使用一份已有充分內容的合成庫存／物流職務檔案，不在鏡頭前從空白重做長訪談。開拍前確認：

- JD 已有可讀的任務、完成條件與來源。
- 至少一筆 JD 引用實際指向工作理解，且下層來源可回查；只有 Memory 存在並不表示 JD 已引用它。
- 至少一項待核對差異可以由畫面直接閱讀，清楚區分「JD 本文變動」與「來源版本變動」。
- PDF 已能實際匯出及開啟，中文、表格與頁面可正常閱讀。
- 畫面操作與錄影版本一致。若展示底部訪談控制或清單刪除確認，先以合成副本核對；刪除不放進主線的成果檔案。

若現有檔案沒有其中某種狀態，先準備錄影副本或改用另一份合成檔案，不修改資料庫偽造模型操作，也不把兩個不同檔案剪成同一次連續訪談。

現有[訪談與來源截圖](../assets/product/interview-and-jd-source.jpg)及[單量更正差異截圖](../experiments/product-validation/data/inventory-demo-guided-20261003/quantity-correction-diff.jpg)可作分鏡參照：兩者均為 2026-10-03 合成庫存示範。前者展示原話來源回查，後者展示 JD 本文更正；它們未展示 Memory 來源換版，也不作為目前底部控制或最終刪除防護的畫面證據。

## 拍攝安排

先拍不需要新模型請求的來源回查、差異與 PDF，再決定是否補一段即時訪談。若回看既有紀錄，畫面標示「既有訪談示範」；若剪除或加速等待，標示「等待時間已縮短」，不要製造即時速度印象。

錄影只取產品視窗，收起開發者工具及私人分頁，不顯示金鑰、連線設定或非合成員工資料。資料庫追查可另錄技術補充，不塞進四分鐘主片。推理摘要可短暫展示處理中的體驗，不稱為完整內部思考或用來證明答案正確。

啟動方式沿[操作手冊](../runbook.md)，不為錄影另造一套產品。開拍前先確認服務、資料與是否有未完成工作；啟動帶金鑰的服務可能接續既有執行。新付費訪談的範圍及上限另行確認，不沿用已結案實驗的授權。
