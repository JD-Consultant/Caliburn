## 離線核對範圍

產品描述核對至 `main@5ff9f7b7d`，包含職務檔案刪除、訪談控制與本機 Docker 交付。早期架構基準 `bf976f36`、Memory 補測基準 `13c0663a` 及其他實驗版本仍保留原有意義；文稿更新不代表重跑實驗。執行時的未提交程式依各實驗 manifest 雜湊辨認。

下列命令只讀已保存原件，不呼叫模型、不修改數據：

```powershell
apps/api/.venv/Scripts/python.exe -X utf8 docs/reports/project-report/verify_evidence.py
apps/api/.venv/Scripts/python.exe -X utf8 docs/reports/project-report/verify_retrieval_evidence.py
```

第一支核對既有指引、來源換版及部分補充實驗；第二支核對 B-28–B-30 共 15 列、主要算術、配置分母及本地來源連結。B.15 的逐題品質與用量另沿該節原件核對，尚未納入這兩支程式。這些核對檢查轉錄與計算，不證明語意真值、全庫召回率、整份 JD 品質或真人效益。
