> **狀態**:設計定案(七層討論逐層鎖定;維護者逐點裁決)。實作計畫:
> [`../plans/2026-07-11-editor-menus-redesign.md`](../plans/2026-07-11-editor-menus-redesign.md);
> 決策紀錄:[ADR 0029](../adr/0029-editor-menus-three-types-decoupling.md)。
> **AI 層(追蹤修訂/對話層/任務盤)整包延後重新設計,不在本份範圍**(見 §11)。

## 1. 背景與問題

現況編輯器的選單「帶智慧」:會自動寫(首開自動套官方)、帶自訂入口(選單內「＋加自訂」footer)、
混合 AI 疊加層(precheck/徽章);且〔選職類〕一次做兩件事——記參考**並且**把順序 1 那份寫進
文件表頭(`PUT /occupations` 服務端寫 `ocs_profile`,documents.py:128-133),「參考了哪些」和
「本表格是哪份基準」綁死。任務的 O/P/K/S 內容藏在四顆「點此填」按鈕後面,整份文件看不到全貌。

維護者定調(2026-07-11 討論):**選單降級成純輸入工具,表格是唯一的編輯與審核場**;
參考選擇與文件身分拆成兩個獨立動作;任務內容全展開像官方文件。

## 2. 設計總則(骨架)

1. **選單三型**(全站只有這三種):
   - **控制選單**:只能選、不可改、不可自訂。單選再點同一項＝清空;多選點＝切換。
   - **參考選單**:多選;列內可改名(**僅已勾的可改**,改的就是文件那筆)、改名**必註記原名**;
     無自訂鈕——自訂一律回表格加列。
   - **素材庫**:無勾選狀態,點一下＝插入一筆/附加一段;選項本身不可改;插入後在表格自由編輯。
2. **選單＝純工具**:無 AI 標記、無自訂入口、**不會一打開就寫入**(首開自動寫全面退場);
   寫入只由明確點擊觸發(選項本身,或「選同X」鈕)。
3. **所有選單一律獨立視窗**(Modal,同一家族),含級別這種短清單;大池窗頂加搜尋框
   (全列照舊,打字只過濾)。
4. **改字不斷根**(全層統一,無容器/葉子之分):改名保留來源身分;選單勾選**不移除**、
   列上顯示原名註記。來源的語義=「從哪裡裁出來的」(出身紀錄),不是「與官方一字不差」。

## 3. 逐欄規格表

文件由上到下(「職類視窗」=維護者對表頭基準單選窗的稱呼):

| 欄位 | 型 | 選幾 | 選項來源 | 備註 |
|---|---|---|---|---|
| 職能基準代碼 | (無選單) | — | 隨職類視窗帶入 | 免填,對齊官方 |
| 職能基準名稱(**職類視窗**) | 控制 | 單 | **已選參考集合** | 代碼＋名稱綁定帶入;自由填名稱路拆除;再點同項=清空 |
| 職類別/職業別/行業別 | 控制 | 多 | 參考身上的官方類別(coded 池) | 拆「＋加自訂列」與自訂列編輯;官方全表入源=縫 |
| 工作描述 | 素材庫 | — | 各參考的工作描述 | 點=附加段落(現況已是);表格 textarea 自由編輯 |
| 基準級別 | 控制 | 單 | 官方 1–6 | 首開自動帶退場 |
| 主要職責 | 參考 | 多 | 職責池(聯集) | 入口搬到表格底部(§6) |
| 工作任務 | 參考 | 多 | 任務池(聯集) | 職責內窗＋**全域窗**(§6) |
| 工作產出(O)/行為指標(P) | 參考 | 多 | 值池;預設=來源任務官方配套 | 拆選單內自訂 footer |
| 職能級別(L,每任務) | 控制 | 單 | 官方 1–6 | 同基準級別 |
| 職能內涵(K)/(S) | 參考 | 多 | 值池 | 同 O/P |
| 職能內涵(A) | 參考 | 多 | 態度池 | **留文件層**獨立區塊(每任務只有 OPLKS,無 A) |
| 說明與補充事項(建議條件/其他補充) | 素材庫 | — | notes 池 | 現況是多選勾選盒→改純插入;插入後表格列自由編輯 |

## 4. 三型行為細則

### 控制選單
- 選項=官方定義,格內**不可能**出現非官方值(結構上防幻覺/防誤植)。
- 三分類現況選項=參考帶到的類別;官方完整三分類表入源後改吃全表(縫,§9)。

### 參考選單
- 列樣式:✓(在文件)＋序號＋名稱＋來源行;無任何徽章式標註(勾選文法先前已鎖:素=不在、✓=在)。
- **列內改名**:僅已勾列可改;改名=改文件那筆(同一筆資料,表格改名同步反映);
  改名後列顯示新名＋原名副行(樣式同來源行細字:「原名:○○○」)。未勾列要客製=先勾入再改。
- 取消勾選=移除該筆;有內容者鎖定(任務四格/級別/筆記非空→表格刪)、他職責已加入→disabled。
- 「選同X」鈕(窗內頂部;取代舊「自動勾選」,**不再於首開自動觸發**):
  - 職責窗/A 窗/三分類窗/基準級別窗:**選同職能基準**(補上主基準來源、還不在文件的項)
  - 任務窗(職責內):**選同主要職責**(補上本職責的官方任務)
  - O/P/K/S 格窗:**選同工作任務**(補上來源任務的官方配套)
  - 職類視窗未選(無主基準)→ 所有「選同職能基準」鈕 disabled。

### 素材庫
- 無勾選狀態、無追蹤;點=插入(工作描述=附加段落;說明欄=加一列);選項不可改名。

## 5. 參考/文件身分脫鉤

比喻:**放手冊上桌**(選參考)和**挑一本當本表格的基準**(職類視窗)是兩個動作。

| 動作 | 元件 | 做什麼 | 不做什麼 |
|---|---|---|---|
| 放手冊上桌 | 〔選職能基準參考〕(原〔選職類〕改名) | 決定參考集合=所有選單的內容;**無順序** | 不寫文件任何欄位 |
| 挑一本 | 職類視窗(表頭單選窗) | 代碼＋名稱綁定帶入表頭;它=**主基準** | 不影響參考集合 |

- **主基準=職類視窗所選那本**(取代「參考順序 1=主基準」)。相似比對/各種預設/「選同職能基準」
  全以它為視角;換選=視角重算(改知識包或前端視角參數)。
- **選單永遠列全部(參考聯集),主基準只換視角不過濾清單**;同名項跨參考合併一列多來源(現況規則)。
- 邊界:表頭未選→選單照開照選、「選同職能基準」鈕全暗;移除的參考正好是文件身分→
  **文件值留著**(已是文件內容)、主基準視角失效(選同鈕暗)、職類視窗可換選;不擋移除、不悄悄清值。
- 現況碼對照:`PUT /{profile_id}/occupations` 停止寫 `ocs_profile`(apps/api documents.py:128-176);
  前端唯一用 `occupation_details[0]` 當主基準的是 UnitPickerMenu:27,改吃 `doc.ocs_profile.ocs_code`
  (DocHeader/AttitudeBlock/DocNotes 已如此);選單啟用條件從「有身分」改「有參考」。
- 〔選職能基準參考〕窗:搜尋＋多選＋套用保留;拆「順序=優先度」UI(順序徽章/標題文案)。

## 6. 功能按鈕

- **〔選職能基準參考〕**:頂欄,改名+去順序+不寫文件(§5)。
- **〔選主要職責〕**:從頂欄搬到**表格底部**,與〔＋新增職責〕並排(選官方/建自訂兩入口站一起)。
- **〔選工作任務〕兩個入口**:
  1. 職責內(現況):任務入該職責。
  2. **全域窗**(頂欄原選職責位):挑任務→自動掛**來源職責**;多來源任務取主基準優先;
     來源職責不在文件→**先自動加該職責再掛任務**;每列副行預告「將掛入:○○職責」(不做黑箱);
     此窗「選同職能基準」=主基準全部職責＋任務整組帶入(一鍵鋪官方骨架)。
  - 取消勾選規則同職責內任務窗(空任務可移、有內容鎖定)。

## 7. 版式:卡片殼三層包含 + OPLKS 全展開

**維持原版卡片殼**(職責卡＋任務卡,把手/就地改名/拖拉/刪除全保留),任務卡內從四顆
「點此填」按鈕換成 **OPLKS 全展開區**;三層同構包含、逐層縮排:

```
╭─ T1 綜理工會會務工作 ──────────── 選任務 ＋任務 ─╮
│  ╭─ T1.1 規劃組織會務 ──────────────────────╮   │
│  │   工作產出(O) ▾  O1.1.1 年度工作計畫      │   │
│  │   行為指標(P) ▾  P1.1.1 蒐集組織內外部…   │   │
│  │                 P1.1.2 諮詢利益關係人…   │   │
│  │   職能級別(L) ▾  4                       │   │
│  │   職能內涵(K) ▾  K01 相關法規            │   │
│  │                 K02 組織章程 …          │   │
│  │   職能內涵(S) ▾  S01 資料蒐集與分析能力…  │   │
│  ╰─────────────────────────────────────────╯   │
│  ╭─ T1.2 辦理會議事務 …(同上一組) ─────────╮      │
╰────────────────────────────────────────────────╯
表格底部:〔選主要職責〕〔＋新增職責〕
其下維持文件層區塊:職能內涵(A)、說明與補充事項
```

- **▾ 掛在左欄標籤上**(工作產出(O)▾ …),點開該格的獨立選單窗——同表頭「▾ 在標籤旁」慣例。
- 內容全展開(不折疊、無「點此填」);列序照官方:O→P→L→K→S。
- **編輯工具 hover 才浮現**(×刪、格底＋自訂、拖拉把手)——靜止狀態=乾淨官方文件。
- 細節:碼等寬字淡色、任務列字重稍高、職責列淡底。
- **位置碼**:表格顯示的 T/O/P/K/S 編碼**依位置自動連號**(第 1 職責=T1、其第 3 任務=T1.3、
  其產出=O1.3.x…),拖拉移動自動重編;**是位子碼不是身分碼**——身分靠來源(URN/provenance),
  原始官方碼收在來源行。
