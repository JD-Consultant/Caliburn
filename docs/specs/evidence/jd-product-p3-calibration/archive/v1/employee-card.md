# C-W 員工扮演卡

版本：1。合成零件倉儲收發員；**公開 calibration，已曝光，非 held-out**。只供人員扮演，不整份送給待測顧問。唯一事實來源為品質材料 §5 C-W；不得混用 CT49、前端 r2、C-M 或 C-S。

## 開場：僅說這一句

「我是零件倉庫的收發員，平常收貨、出貨，也用試算表，想把自己的工作整理清楚。」

## 依自然追問可說的已設定內容

不必照表順序，也不必照抄措辭；只回答問題相關內容。未設定的姓名、公司、主管職稱、系統品牌、貨量、學歷、年資、證照、目標或其他條件，回答「目前不清楚」。不能為讓顧問通過而補理想答案。

| ID | 可回答的事實 |
|---|---|
| W01 | 我核收貨品號、數量、外箱與到貨單；批號件另外核對批號。差異先標記待釐清，交採購聯絡供應商；我不改採購價格。 |
| W02 | 出貨依已核准揀貨單核品號／數量、包裝、記錄交運資料。缺件先回報業務，不自行替代料號。 |
| W03 | 收貨留下入庫紀錄、差異交接資料。入庫紀錄需能追到到貨單；批號件不能漏批號；差異未釐清不列可用庫存。 |
| W04 | 我比對實物與庫存記錄，重點查混料、重複入帳；差異先複點並查出入庫資料，再交主管決定帳務調整。 |
| W05 初述 | 「印象中每月全部盤點。」保留「印象中」，不要先說成確定；晚期查證內容另列下方。 |
| W06 | 年度停工前我整理封存批次清單供追溯；不是銷毀核准。去年一次幫忙清點退貨，不是固定客服工作。 |
| W07 | 必須懂品號、批號與庫存記錄的對應、差異處理流程；會交叉比對單據和實物、追查差異及說明交接。收貨與盤點都用到這些。 |
| W08 | 我只處理小型零件，沒有開堆高機；最重物件重量我不確定。 |
| W09 | A案少兩盒是到貨差異；B案帳多兩盒是重複入帳。兩案不能用同一處理結論。 |
| W10 | 「有沒有庫存正確率目標我不清楚；我確定有上面說的核對要求。」 |

## 晚期 W05 查證更正：獨立事件

前述盤點印象已說過後，在晚期自然續談時說：

「我查證了，前面說印象中每月全部盤點要更正：每週只循環盤 A 類料，每季才全庫盤點。」

更正只涉及盤點周期與範圍；不提供新的出貨周期。若初述從未揭露，不能假稱之前說過；改以查證後內容回答，記為首次確認，該 trial 的晚期更正效果仍未觸發。

## M-W1：純文件手改，不是訪談事實

在已有 JD、App 允許手編時，僅透過文件編輯加入：

「每月底提出補貨建議」

不在聊天說此句是目前責任，不替它掛訪談來源，也不要求執行任何工具或 Memory 動作。記錄實際保存與手改位置。這不增加 W01–W10 的真相。

### M-W1 後續澄清：另一次聊天事件

顧問若中立詢問是否現在的責任，或後續正常澄清回合，回答：

「這是我想新增的工作，目前還沒做。」

這段聊天才是明示願望／現責區別的來源；不把它倒算成純手改時已有的訪談證據。
