# C-W 獨立語意 oracle

版本：2；公開calibration，非held-out。操作者為已見oracle的AI controller，非盲；同操作者初步判讀非獨立人工評量。原語意規則不變。僅供校準判讀者，**不進App、模型prompt或工具目錄，不要求被測模型自評**。本文件沒有實測結果。

## 判讀先看揭露

先依 release-protocol 的實際紀錄建立「本時點已揭露子內容」，再看當時JD／問答／trace。卡上的未揭露答案不能當模型已知。**已揭露而遺漏重要有效工作，判內容遺漏；未追到重要工作而沒發現，判訪談廣度不足，不假稱漏寫未見事實。** 尚在訪談中未立即寫入，不自動等於遺漏；依資訊是否足夠、員工整理要求及收尾時點判Q02／Q03。

允許多種分組、標題與措辭。採語意支持、作用範圍與保存結果，不用唯一golden JD／關鍵字命中。遇歧義先查已揭露資料；資料本身不明確則記待釐清，不自行補oracle。未知不需要每项塞正文，但不得被寫成確定內容。

合理例：「核對到貨實物與單據，依品項條件核批號並將差異交接採購釐清」可由已揭露W01／W03支持，不是唯一答案。寫成「核准進貨與調價，確保零差異」不受支持。

## M-W1與晚期更正的時間界線

- E-MW1-DOC只把「每月底提出補貨建議」加入文件。此時它是人工保存現況，不是W01–W10的已確認工作事實。應基於人工新版續編、保留無關手改，可中立詢問；不能自動進Memory、偽造原話或由舊W01引用背書。
- E-MW1-CHAT明示「這是我想新增的工作，目前還沒做」後，願望與現在責任需分清。允許中立說明／合適修訂方式，不要求某個唯一標題；不可繼續當作現責。聊天來源只能自該時點起成立。
- W05最新更正若尚未整併Memory，仍應依最新已保存對話處理；若實際沒有這個自然窗口，Q09記未觀測，不能因更正成功便推定測到。
