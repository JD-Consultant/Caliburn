職務目的

將客戶確認的需求與視覺設計實現為可使用、可維護的網站前端，完成品質確認及交付，並依各專案的服務約定處理上線後問題與維護工作。（固定驗證新增：交付前確認接收窗口。）

主要職責與工作任務

一、釐清需求與規劃前端交付

1. 釐清前端功能、使用情境及驗收範圍。

與專案經理及客戶窗口確認網站需要支援的主要操作、裝置、瀏覽器與關鍵異常情境，整理開發範圍及尚待確認的事項。

  • 主要產出：可供開發與確認的前端需求及驗收範圍紀錄。

  • 完成要求：已確認與尚未確認的內容可以區分；不把推測直接當作客戶同意的需求。

2. 評估前端工作量、依賴條件及需求變更的影響。

依工作範圍評估開發投入，辨識後端介面等依賴，說明變更對既有功能及交付安排的影響，提供調整建議。

  • 完成要求：估算包含必要前提與限制；新增或變更工作由專案經理協調確認後納入安排，不自行承諾報價或客戶期限。

二、開發網站前端與整合資料介面

3. 實作網站頁面、版面及互動功能。

依已確認的需求與視覺設計開發前端，處理約定裝置與瀏覽器的差異，讓主要操作符合預期。（固定驗證：同 ID 正文也已更新。）

  • 主要產出：可供整合與檢查的前端頁面及程式版本。

  • 完成要求：主要操作、約定的鍵盤操作與基本可用性要求納入實作；發現設計與需求不一致時，先確認再調整。

4. 串接後端介面，處理資料與各種操作狀態。

依介面約定實作資料顯示，以及載入、成功、失敗、逾時等情境的前端行為，並與後端工程師釐清問題及責任範圍。

  • 完成要求：﻿

    • 查詢逾時時，保留必要輸入並提供重試方式。（固定驗證：重試保留查詢條件。）

    • 訂單送出結果不明時，避免使用者重複送出，並與後端確認實際狀態，不直接判定下單失敗。

    • 涉及後端資料或業務規則時，與負責人員確認，不自行改定規則。

三、確認品質與完成交付

5. 檢查前端功能，修正並驗證交付前的缺陷。

檢查主要使用流程、約定的異常情境，以及裝置與瀏覽器的支援情況；記錄問題、修正前端缺陷並確認相關影響。

  • 主要產出：檢查結果、缺陷處理紀錄及待解限制說明。

  • 完成要求：修正後確認原問題及受影響操作；未解事項交由專案經理協調，不自行宣稱已通過客戶驗收。

6. 準備前端交付內容，配合發布、驗收與維護交接。

整理可辨識的交付版本、操作或維護說明、已知限制及交接事項，並配合處理發布過程中的前端問題。

  • 主要產出：交付版本及接收者可使用的交接說明。

  • 完成要求：交付版本與檢查結果一致；發布問題能提供重現資訊；涉及服務端部署時，與負責該部署的後端工程師協作。客戶驗收仍由客戶確認。

四、處理上線問題與約定維護

7. 處理約定範圍內的上線後前端問題。

收到問題後，了解影響與重現條件，區分前端缺陷、後端問題或新增需求；依判斷進行修正、驗證或轉交適當人員。

  • 執行時機：上線後發生屬於服務範圍的問題時，包含少見但影響主要操作的異常。

  • 完成要求：記錄處理結果與未解事項；未排除的問題不能標成已解決。處理優先順序及對外承諾由專案經理協調。

8. 依維護約定執行定期前端檢查。

對包含定期維護的專案，檢查主要前端操作，記錄結果並追蹤已知問題或必要調整。

  • 執行時機：依各案約定；目前包含月檢服務的專案按月執行。

  • 主要產出：維護檢查及問題追蹤紀錄。

  • 完成要求：僅約定交付後缺陷修正的專案，不自動納入固定月檢；超出服務範圍的新增需求另行確認。

工作條件與責任邊界

  • 日常以電腦開發、檢查及線上協調為主，依專案安排工作；本職位無固定輪班或例行出差。

  • 本人負責前端技術處理與建議，不承擔人員管理。專案經理協調優先順序、工作範圍及對外承諾。

  • 商務開發、報價、簽約及帳務不屬本職位；視覺設計、後端業務規則、服務端部署及一般客服由相應人員負責。

  • 維護依各案服務範圍及周期執行，不因此包含全天候值班或未約定的回應時限。
