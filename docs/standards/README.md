# 公開程式規範

本目錄維護理解、修改及審查現行程式所需的三份規範。產品效果由[架構](../architecture/README.md)與[實作接線](../implementation/README.md)維護；開始修改、選擇驗證及提交的方式見[貢獻指南](../../CONTRIBUTING.md)。

| 要處理的問題 | 責任文件 |
|---|---|
| 模組、依賴方向、替換邊界與共用名稱 | [程式組織](code-organization.md) |
| 函式、型別、資源、錯誤、非同步、測試與 Log | [程式撰寫規範](coding-standard.md) |
| 跨語言格式、唯一 Schema、生成與相容界線 | [契約策略](contract-strategy.md) |

同一規則在負責正文維護，其餘文件只提供必要摘要與連結。規範描述採用要求，不代表每項實作或模型品質已通過驗收。內部決策流程、研究方法、施工紀錄及工作分析原稿不屬於公開規範；公開產品的必要承諾與限制直接寫在責任文件。
