# 客製化職務說明書撰寫與修訂

把員工實際工作整理成他自己的 JD。不是套用職稱公版，也不是評分員工。
這是同一主顧問的按需方法；日常訪談、案例整理與工作理解整理不必載入，
也不要求每輪改稿或等整場訪談完才寫。

## 何時寫、何時繼續談

- 某項工作已能辨識對象、本人行動、目的／結果及重要條件和責任邊界，即可寫有根據的部分。
  未知成果、要求、知識或技能可以留空；只有職稱、工具名稱或單一案例不足以造完整稿。
- 新責任、影響理解的條件或實質更正才修改相應內容。重述、致謝或同類佐證可以只留在訪談與 Memory。
  員工要求整理且已有足夠資訊時，不以不相關追問延遲成稿。
- 有影響的矛盾未釐清先問；已說不知道的資訊保留限制，轉談其他有用方向。

## 寫稿與修正

按需讀取 `/skills/write-customized-jd/references/writing-and-correction.md`。
先讀目前 JD；以目前工作理解掌握穩定工作與整體範圍，按需讀相關案例保留條件、例外及責任差異，
需要確認依據、更正或邊界時再沿引用讀必要的原始訪談。不要只看單一回合完成整份映射。
同時考慮最新已保存、但尚未被背景 Memory 整理承接的對話；員工本輪明確更正不能被較舊理解蓋回。
手改是目前文件，不自動成為訪談事實；收到 App 變更通知後，以最新版續編並保留無關手改。

使用已提供的 JD 工具讀目前稿、定位和保存。只用工具發配的目標、選取及關聯引用，
不猜位置或持久識別；初建知識或技能後，重新讀取 App 發配的同版引用再連結。
來源只使用已取得的依據，不能用一個存在的來源替不受支持內容背書。

依工具實際結果說明已保存、未改變、失敗或尚待查明。意圖、畫面候選與工具呼叫送出都不等於保存成功。
結果未知依既有查回／停止方式處理，不為補一個成功回覆重新執行已成功的修改。

## 全份核對與收尾

需要補工作範圍或全面核對時，按需讀取 `/skills/write-customized-jd/references/complete-work-guide.md`。
同時核對工作→JD 有無遺漏，以及 JD→工作有無補造責任、要求、資格或知識／技能。
重要低頻責任、例外與最新更正不能只因最近沒提就消失。
說明目前已涵蓋與尚待確認的範圍，讓員工有補充／更正機會；不要把欄位填滿、沉默、輪數或自評滿分當完整證明。

本 Skill 只提供寫作方法，不是員工事實，不修改 Memory，也不授予主機寫檔、執行、網路或額外 Agent 能力；
JD 保存、關聯、版本、身分與錯誤恢復仍依 App 工具契約。
