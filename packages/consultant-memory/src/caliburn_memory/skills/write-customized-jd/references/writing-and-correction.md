# JD 成文與有界修訂

目標是讓不了解訪談的人也能看出這個職位為誰做什麼、本人負責到哪裡、形成什麼成果、
如何算適當執行、需要哪些專業，以及有哪些重要條件與權責邊界。客製深度看辨識力，
不看字數、頁數或固定任務數。O／P／K／S 是內部對照語言，成品使用完整名稱。

## 文件層次

- **職務目的**：短段落交代服務對象、主要工作範圍與持續價值；不重抄所有任務或虛構績效目標。
- **主要職責**：按有意義的工作目的或責任範圍分組；不只按案件、工具、月份或產品名稱分組。
- **工作任務**：說清楚本人對什麼採取什麼行動，並保留理解工作所需的結果、條件、頻率、權限或交接。
  工具與單一步驟不能冒充任務；不同責任也不能只因最終目的相同就硬併。

職務目的、職責與任務是同一份工作的不同縮放程度。任務不能只剩短標題，也不把所有操作拆成流水帳。
若拿掉其中一部分或交給別人後，剩餘責任已無法辨識，才考慮分項；不按動詞數量機械切分。

## 任務底下的成果與工作執行要求

- **成果／產出（O）**說明工作形成、交付或維持了什麼，以及必要的接收用途。服務或維持狀態也能是成果，
  不為填欄位虛構報告，也不機械重抄任務句。
- **工作執行要求（P）**說明適當執行、完成或持續維持工作所需的品質、條件、檢查、異常處理及交接要求。
  它可約束過程、成果品質、交付或持續狀態。

成果與要求各自可有多項，平行放在任務底下，不一對一、不互為父子，也不與任務敘述合併。
未知項目可暫缺，不能為了整齊而補造。整項任務的頻率、權限與適用限制寫在任務敘述；
某項要求的條件與該要求放一起。真正跨任務共通的條件才集中，不把局部約定套到所有工作。

已確認的期限和數字保留原適用範圍；未說的 KPI、時限、錯誤率、法規要求或認證不得補造。
單次成功、失誤、趕工、個人期待或未來願望不是職位的正常執行要求。

## 所需知識、所需技能與必要資格

- **所需知識（K）**是完成工作需要理解的概念、原理、規範與領域內容。
- **所需技能（S）**是運用方法與專業完成工作、判斷及解決問題的能力。

寫到足以辨識內容、用途及適用範圍，避免只有「專業知識」「溝通能力」等泛稱，
也不傾倒百科、學歷、興趣或用不到的工具名。同一 K／S 可支援多個任務，正文定義一份，
按內容、用途與範圍去重；每條任務關聯都要有實際工作支持，不把所有項目掛到所有任務。

員工持有證照、學過工具或想進修，不等於職位必要資格；具備技能也不等於擁有批准權。
必要資格或授權須有可靠依據。安全、倫理或協作若確實影響工作，寫成具體責任、要求或技能，
不自造態度、能力級別、個人評分或訓練計畫。

## 有界修訂

讀取最新版及 App 的人工變更通知，核對更正影響的對象、時間與範圍。明確更正取代受影響結論，
但不連帶刪除其他有效工作；條件應在所有相關敘述一致，不只修改聊天回覆。
疑似衝突但沒有明確更正時先釐清，不因新一句較晚便全面覆蓋。

背景 Memory 尚未納入員工剛說的明確更正，也要依最新已保存對話修訂，但不假稱已整併。
員工手改是目前文件，要保留無關修改，但不自動成為訪談事實、Memory 或已確認責任。
修改後依實際保存結果與前後差異說明；失敗不宣稱完成，未知先沿既有工具查明。
